# R190 — 假日"stay-home 剂量"（0 token）：居家越少的工作日户，假日增幅越大（趋势）

- **轮次**：Round 190
- **日期**：2026-09-12
- **验证层级**：**L0**（复用 7 住户 baseline/holiday 各 15 run；**0 token**）
- **结论**：假日总增量与**基线日间(9–17)占比**呈**负相关 r=−0.47（p=0.29, n=7）**：
  工作日**白天离家**（日间占比低）的户，假日增幅**更大** → 支持 **stay-home 剂量**机制（描述性，n 小）。

---

## 1. 目的

机制检验：holiday 增幅是否与住户**基线"白天是否在家"**成正比（stay-home 剂量）？

## 2. 方法（0 token）

对 7 住户：取 baseline 均值日间(9–17)占总量比（=工作日离家程度），与 holiday 总电量 Δ% 求相关。

## 3. 结果

| 住户 | 基线日间(9–17)% | holiday 总 Δ% |
|---|---|---|
| W3 h002 | **6.5** | 39.8 |
| W1 h002 | **8.9** | 48.3 |
| W3 h003 | 13.0 | 64.5 |
| W2 h002 | 19.9 | 31.9 |
| W2 h001 | 20.9 | 59.1 |
| W3 h001 | 22.0 | 19.3 |
| W1 h001 | **24.0** | 20.8 |

- **Pearson r = −0.47（p = 0.285，n=7）**。

## 4. 解读

1. **负相关趋势**：基线日间占比越低（工作日越"离家"）→ 假日总增幅越大
   （W1h002 8.9%→+48%、W3h002 6.5%→+40% vs W1h001 24%→+21%）→ **stay-home 剂量**方向；
2. **不显著**（n=7）→ **描述性**，需更多住户（或按"离家时间"建模）方能定论；
3. **与机制一致**：假日效应来自"把工作日在外的时间转为居家用电"，故**通勤型住户**受益（加载）更大。
