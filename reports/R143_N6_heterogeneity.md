# R143 — N6 异质性（RQ3）：同一热浪事件在不同住户响应分化

- **轮次**：Round 143
- **日期**：2026-09-11
- **验证层级**：**L2 真调**（world_838587 **house_0001** M1；baseline×9 + heatwave×9；~72 calls）
- **结论**：⚠️ **异质性**：h001 M1 热浪→AC 仅 **0/9 → 4/9（Fisher p≈0.08）**，弱于 h002 M1 的强响应

---

## 1. 目标（N6）

RQ3：同一政策/事件在不同住户是否**分化**？以**二值**（AC on/off，漂移免疫）测 heatwave 在
**house_0001**（客厅 AC，4 口之家）上的响应，与已确立的 house_0002 对比。

## 2. 方法（可复现）

```powershell
python run.py --mode simulate --world world_838587 --house house_0001 --member 0 --days 1 --env "n6_b_$i"
python run.py --mode simulate --world world_838587 --house house_0001 --member 0 --days 1 --env "n6_h_$i" --event-template "2026-09-11|heatwave"
```

## 3. 结果（n=9）

| 指标 | baseline | heatwave | Δ | t/Fisher |
|---|---|---|---|---|
| **AC 启用（二值）** | **0/9** | **4/9** | — | **Fisher 双侧 p≈0.08** |
| AC kWh | 0.000 | 0.411 | — | t=2.41 |
| 峰段 kWh | 3.117 | 3.448 | +10.6% | t=0.85（n.s.） |
| 总 kWh | 9.557 | 9.682 | +1.3% | t=0.22（n.s.） |

## 4. 解读（RQ3 异质性）

- **方向一致但强度分化**：h001 M1 热浪→AC **4/9**（边缘显著），远弱于 h002 M1 的强响应
  （h002 在既有实验为 6/6、11/12 等）；
- → **同一事件、不同住户的响应强度显著不同**（与 Costa & Kahn 2010"同政策异质响应"一致）；
- **二值 outcome 漂移免疫**，故该分化**非漂移伪影**；
- **限制**：单成员、单世界；异质性来源（AC 位置/居住模式/人格）需进一步分离。

## 5. token 消耗

## 6. 结论
N6（异质性）= **成立**：heatwave→AC 在 h001 M1 弱（0/9→4/9）、h002 M1 强 → **住户间响应分化**（RQ3 证据）。
