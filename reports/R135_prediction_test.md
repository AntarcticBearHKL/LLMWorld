# R135 — 机制预测检验（world_143345, AC峰段占比 26%）：**AC-峰段 −44.7%**（三世界剂量-反应）

- **轮次**：Round 135
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_143345 h002M1；**交错** heatwave×9 + (heatwave+靶向信息)×9；~72 calls）
- **结论**：⚠️ **部分证实**：靶向信息使 **AC-峰段组件 −44.7%（t=−2.45, p≈0.04）**，但总峰段仅 −10.0%（n=9 不显著）→ **三世界剂量-反应**

---

## 1. 目标

R131 机制：设备靶向的削峰 = **目标设备峰段负荷 × 行为改变率**。
**预测**：world_143345 h002（AC 峰段占比 **26%**，来源 0-token 分析）上，靶向信息应显著降低 AC-峰段组件。
本轮**前瞻检验**该预测。

## 2. 方法（可复现）

```powershell
$TI = "2026-09-11|Peak air-conditioner request|To help balance the grid this evening, please avoid using your air conditioner between 5pm and 8pm today."
foreach ($i in 1..9) {
  python run.py --mode simulate --world world_143345 --house house_0002 --member 0 --days 1 --env "mb_$i" --event-template "2026-09-11|heatwave" --workers 1
  python run.py --mode simulate --world world_143345 --house house_0002 --member 0 --days 1 --env "mt_$i" --event-template "2026-09-11|heatwave" --event $TI --workers 1
}
```

## 3. 结果（n=9）

| 指标 | heatwave | +靶向信息 | Δ | 配对 t(df=8) |
|---|---|---|---|---|
| **AC-峰段组件 kWh** | 1.267 ± 0.328 | 0.700 ± 0.765 | **−44.7%** | **−2.45（p≈0.04）** |
| 总峰段(16–21) kWh | 4.906 ± 0.866 | 4.416 ± 1.325 | −10.0% | −0.92（n.s.） |
| AC kWh | 8.600 ± 0.397 | 7.900 ± 2.153 | −8.1% | −1.06（n.s.） |
| 总电量 kWh | 16.672 ± 1.231 | 15.752 ± 2.000 | −5.5% | −2.42 |

- **预测命中**：AC-峰段组件**显著下降 −44.7%**（设备的峰段负荷确被削减）；AC 启用 9/9→9/9（未见关停，仅减量）。

## 4. 三世界剂量-反应（靶向信息 → 峰段）

| 世界 | baseline AC-峰段 kWh | AC-峰段 Δ | **总峰段 Δ** |
|---|---|---|---|
| world_838587 | 0.16（5%） | ~0% | **+12.2%（n.s.）** |
| world_143345（本轮） | 1.27（26%） | **−44.7%** | −10.0%（n.s.） |
| world_172148 | 1.62（30%） | **−63%** | **−25.5%（显著）** |

- **总峰段效应 ≈ baseline AC-峰段负荷 × 行为改变率**：剂量越大（AC 峰段负荷越高、改变越多），削峰越强；
- **三世界单调一致**（+12% → −10% → −25.5%），**机制预测成立**（方向与剂量-反应均符合）。

## 5. 解读

- **机制确认（三世界剂量-反应）**：设备靶向能否削峰取决于**该设备在峰段的绝对负荷**（剂量）；
- **非二值**：三世界皆未使 AC **关停**（R135 9/9 仍开），而是**减量**——与设备/居住结构相关；
- **n 限制**：world_143345 总峰段 −10%（n=9）未达显著，但 **AC-峰段组件显著**，且与剂量-反应一致；
- 与 R131 一致：**"价格×靶向 2×2"非机制**，真正变量是**目标设备的峰段负荷剂量**。
