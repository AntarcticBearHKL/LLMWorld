# R074 — storm 事件：无效（null）

- **轮次**：Round 74
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_838587 house_0002 M1；storm vs baseline；~4 calls）
- **结论**：⚪ **无效**：storm 事件几乎不改变行为（总量 −1.5%，日间不变，Out 615→600、无显著变化）

---

## 1. 目标

R066/R069 建立了"环境/社会事件 → 大效应二值"的证据集（热浪/寒潮/封锁）。本轮测试
`storm` 事件是否也产生大效应（guide §5.1："Blackout panic → emergency usage；减少非必需"）。

## 2. 设计（可复现）

```powershell
# baseline 复用 tou_ctl
python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 `
  --env storm_run --event-template "2026-09-11|storm" --workers 1
```

## 3. 结果（2026-09-11）

| 臂 | 总 kWh | 峰 W | 日间 9–17 kWh | Out 分钟 |
|---|---|---|---|---|
| baseline | 8.193 | 3320.1 | 0.649 | 615 |
| **storm** | 8.068 | 3121.1 | 0.649 | 600 |

- 总电量 **−1.5%**（远小于噪声地板 CV≈12%）；日间负荷**完全相同**；Out 分钟无实质变化。

## 4. 解读

- **storm 是 null**：与热浪/寒潮/封锁不同，storm 未触发大效应二值行为；
- 合理原因：模板文本（"severe storm this evening, possible outages"）**不改变当日作息结构**
  （不像高温/低温改变设备需求、封锁改变在家时间），只是信息性预警；
- 与 R058 一致：**不是所有事件都有大效应**；平台可判的是"改变行为结构"的事件；
- 属 R058 认定的"不可判/无效应"类型。

## 5. token 消耗（估算）

- 1 个 storm run × (4 步 × 1 成员 × 1 天) ≈ **4 次调用**。

## 6. 论文更新

- **不进 `paper/`**（无有效果，符合 §6 分流）；仅本 report 记录。

## 7. 结论

`storm` 事件无显著行为效应——与三个（热浪/寒潮/封锁）**改变行为结构**的事件形成对照，
进一步界定"哪类事件可在此平台产生可判效应"：**仅有改变设备需求或居家/外出结构的事件**。
