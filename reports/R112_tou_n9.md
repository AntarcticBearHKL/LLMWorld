# R112 — TOU 扩样 n=9：**峰段 null（−2.2%）**，但总电量 **+13.1%**（过度遵从）

- **轮次**：Round 112
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_838587 h002M1；**交错** baseline×9 + tou×9；补 6 对 ~48 calls）
- **结论**：❗ **推翻 R111 的 −17.5%**：n=9 峰段仅 **−2.2%（n.s.）**；总电量 **+13.1%**（7/9 对，t=2.11，非漂移）

---

## 1. 目标

R111（n=3）给出 TOU 名义 −17.5% 削峰（n.s.）。本轮**扩样至 n=9** 判定其真伪。

## 2. 方法

```powershell
foreach ($i in 1..9) {
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 --env "tb_$i" --workers 1
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 --env "tt_$i" --policy tou --workers 1
}
```

## 3. 结果（n=9，配对）

| 指标 | baseline | tou | Δ | 配对 mean±std | t(df=8) |
|---|---|---|---|---|---|
| 总电量 kWh | 7.754 ± 1.065 | 8.771 ± 0.911 | **+13.1%** | **+1.018 ± 1.444** | **+2.11** |
| 日间 kWh | 0.695 | 0.793 | +14.2% | +0.098 ± 0.284 | +1.04 |
| 峰段(16–21) kWh | 3.580 ± 0.519 | 3.502 ± 1.038 | **−2.2%** | −0.079 ± 0.838 | **−0.28** |

**漂移检验**：总电量对全局运行次序回归斜率 = **−0.0000 kWh/run** → 非单调漂移；
总电量配对差 7/9 为正：[−0.56, −0.27, +0.82, +1.78, +1.74, +1.16, +3.68, −0.93, +1.73]。

## 4. 解读

- **R111 的 −17.5% 是小样本假象**：n=9 时峰段效应塌缩到 −2.2%（t=−0.28）→ **TOU 无削峰**；
- **总电量 +13.1%（t=2.11，双侧 p≈0.067）**：7/9 对为正，且**非漂移**（斜率≈0）——
  提示 TOU 文本触发**过度遵从**（为"峰移"多开高功率家电），总能耗**净增**；
- 与 R026"方向不稳"、R040"过度遵从"、主线"软/价格干预效应弱/反向"一致。

## 5. token 消耗（估算）

- 12 个 run × (4 步 × 1 成员 × 1 天） ≈ **48 次调用**（本轮）；累计 TOU 72 call。

**TOU 对峰段无效应（−2.2%）；总电量倾向上升（+13.1%，borderline）**。
这是**小样本假象**的又一实例（n=3 不可信），再次支持 R104/R057 的方法学红线。
