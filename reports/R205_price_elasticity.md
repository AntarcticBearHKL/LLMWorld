# R205 — 价格剂量-反应（弹性）：价差 × cost-context → **峰 −7.3% / 谷 +14.8%**（显著）

- **轮次**：Round 205（P3 剂量-反应）
- **日期**：2026-09-12
- **验证层级**：**L2 真调**（world_838587 h002；低价差 tou:0.5 vs 高价差 tou:1.2，**两臂均开 cost-context**；共享 s4-only；~30 calls）
- **结论**：✅ **剂量-反应成立**：峰谷价差 2.4×（0.5→1.2，**7× 差异**于谷率 0.18 的倍数）使移峰**显著增强**
  （**峰 −7.3%（p=0.0095）、谷 +14.8%（p=0.014）**）→ **平台出现价格弹性**。

## 1. 目的

R180 曾示"纯文本下 7× 价差无剂量-反应"（null）。本轮在 **cost-context 开启**下检验价差是否**单调增强移峰**
（RQ2：价格弹性；Albadi & El-Saadany 2008；Wang 2021）。

## 2. 方法（可复现）

```powershell
# 共享时间线；两臂均注入成本表
python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --date 2026-09-11 --env "pxlo_$i" --policy "tou:0.5,0.18" --cost-context --s4-only --workers 1
python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --date 2026-09-11 --env "pxhi_$i" --policy "tou:1.2,0.18" --cost-context --s4-only --workers 1
python src/analyze/compare_cpp.py --world world_838587 --house house_0002 --date 2026-09-11 --base-prefix pxlo --treat-prefix pxhi --n 15 --tag tou --base-tag tou
```

## 3. 结果（n=15，低价差 → 高价差）

| 指标 | tou:0.5,0.18 | tou:1.2,0.18 | Δ | t | p |
|---|---|---|---|---|---|
| **峰段 16–21** | 2.701 | 2.503 | **−7.3%** | **−3.00** | **0.0095** |
| **谷期 22–7** | 2.583 | 2.966 | **+14.8%** | **+2.82** | **0.014** |
| 总电量 | 9.326 | 9.314 | −0.1% | −0.06 | 0.95（n.s.） |
| Dishwasher | 0.569 | 0.760 | +33.7% | +2.82 | 0.014 |

## 4. 对照（同户 W1 h002）

| 设计 | 峰段 | 判定 |
|---|---|---|
| 价差 0.5→1.2，**无 cost**（R180） | +1.6% n.s. | ⚪ 无剂量-反应 |
| 价差 0.5→1.2，**有 cost**（本轮） | **−7.3%（p=0.0095）** | ✅ **剂量-反应** |

## 5. 解读

1. **价差越大、移峰越强**（峰↓谷↑，总量不变）→ **价格弹性可测**（此前 R180 不可测，因缺 cost-context）；
2. **机制**：cost 表把价差**换算成金额差**（高费率→更大节省）→ agent 据此**单调增强**移峰；
3. **对齐文献**：方向与 Faruqui/Albadi 的价格弹性一致；**平台现已具备"价格-行为"定量分析能力**；
4. **意义**：这正是用户所问"如何让系统对价格类问题有分析效果"——**由 null 变为显著剂量-反应**。
