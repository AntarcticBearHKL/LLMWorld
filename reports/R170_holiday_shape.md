# R170 — 公共假日"时段前移"机制（0 token）：08:00↑、12:00↑、**18:00 峰↓（3/3 世界）**

- **轮次**：Round 170
- **日期**：2026-09-12
- **验证层级**：**L0 分析**（复用 R166–R168 的 90 个 holiday env；**0 token**）
- **结论**：假日把负荷**从傍晚前移到日间**：三世界 **08:00 +1.5~1.9 kWh、12:00 +0.6~1.2 kWh、18:00 −0.3~1.3 kWh**
  → 解释"总量稳健上升、峰段方向世界相关"。

## 1. 目的

R166–R168 显示 holiday 总电量跨 3 世界稳健上升（+32~48%），但**峰段方向不一致**（+/+/−）。
用时均曲线定位能量去向，解释该不一致。

## 4. 解读（机制）

1. **时段前移（morning/midday shift）**：假日居家使**早餐/上午居家用电（08:00 大增）**与**午餐/日间活动（12:00 增）**
   上升，同时**傍晚通勤后的做饭峰（18:00）下降** → 负荷形态由"晚峰型"转向"日间型"；
2. **解释峰段不一致**：16–21 窗口内 18:00 降、但 16–17 可能升 → **净峰视住户作息而定**（故峰不作断言）；
3. **解释总量上升**：日间多项活动（多餐、照明、TV、电脑）叠加 > 晚峰减少量 → 总量 +32~48%；
4. **与 lockdown 一致**：同型 stay-home 机制（Xia 2026）——居家 → 日间用电↑、晚峰结构改变。
