# R057 — 量化"运行间噪声地板"（0 token，用既有同配置运行）

- **轮次**：Round 57
- **日期**：2026-09-11
- **验证层级**：L0（复用既有运行产物；**0 token**）
- **结论**：✅ 用**完全同配置**的 3 次运行量化噪声：std ≈ **1.01 kWh**（CV ≈ **12%**），
  极差 **7.37–9.80**（最高比最低 **+33%**）——**任何小于此的处理效应在单次水平不可辨别**

---

## 1. 目标

R047/R054 断言"单次运行方差压倒效应"。本轮用**完全相同的配置**多次运行（复用既有 env）**量化**噪声地板，
为论文 validity 提供硬数字。

## 2. 方法（0 token）

配置完全相同：`world_838587` / `house_0002` / `Member 1` / `2026-09-11` / 无政策 / 无事件 / 推理模式，
仅**运行实例**不同。用 R056 工具 `aggregate_runs.py` 汇总：

```powershell
python src/analyze/aggregate_runs.py --world world_838587 --house house_0002 --date 2026-09-11 `
  --member "Member 1" --envs tou_ctl sched_ctl world_838587
```

## 3. 结果

| env（同配置） | 总 kWh |
|---|---|
| `tou_ctl`（R023 基线） | 8.1935 |
| `sched_ctl`（R046 对照，第 1 天） | 7.368 |
| `world_838587`（并发基线） | 9.800 |

**汇总**：n=3，**mean = 8.4538**，**std = 1.0098**（CV ≈ **11.9%**），min 7.368，max 9.800。

## 4. 解读（关键）

- **噪声地板 ≈ ±1.0 kWh（~12%）**，极差达 **2.43 kWh（最高比最低 +33%）**。
- 因此：**任何幅度小于 ~12–30% 的单次处理对比都不可靠**——这解释了：
  - nudge 小样本"5/5 全负"却在更大样本出现 3/7 增耗（R054）；
  - TOU 方向随设置翻转（R026）；
  - R045 的"回弹"被对照证伪（R046）。
- **唯一稳健的是二进制/定性信号**（热浪→AC on/off），因为其效应量远大于噪声地板。

## 5. 论文更新

- `paper/99_discussion.md` Threats-to-validity：加入量化噪声地板（mean 8.45 / std 1.01 / 极差 +33%），
  明确"单次小样本幅度不可作为结论；须 N 次平均使标准误 ≈ std/√N"。
