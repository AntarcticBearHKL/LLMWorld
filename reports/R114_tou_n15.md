# R114 — TOU 扩样 n=15：**峰段与总电量皆 null**（前两次均小样本波动）

- **轮次**：Round 114
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_838587 h002M1；**交错** baseline×15 + tou×15；补 6 对 ~48 calls）
- **结论**：⚪ **null**：峰段 **−3.2%（t=−0.41）**、总电量 **+5.4%（t=0.98）**，均不显著

---

## 1. 目标

R112（n=9）总电量 **+13.1%（t=2.11，borderline）**，R111（n=3）峰段 −17.5%。本轮**扩样至 n=15** 判定。

## 2. 方法

```powershell
foreach ($i in 1..15) {
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 --env "tb_$i" --workers 1
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 --env "tt_$i" --policy tou --workers 1
}
```

## 3. 结果（n=15，配对）

| 指标 | baseline | tou | Δ | 配对 mean ± std | t(df=14) |
|---|---|---|---|---|---|
| 总电量 kWh | 8.215 | 8.658 | **+5.4%** | +0.443 ± 1.760 | **+0.98** |
| 日间 kWh | 0.737 | 0.736 | −0.3% | −0.002 ± 0.287 | −0.03 |
| 峰段(16–21) kWh | 3.715 | 3.598 | **−3.2%** | −0.117 ± 1.109 | **−0.41** |

**漂移检验**：总电量–次序回归斜率 = +0.019 kWh/run（轻微正漂移；同对相邻 → 影响可忽略）。

## 4. 三阶段对照（关键：小样本假象）

| N | 峰段 Δ | 总电量 Δ |
|---|---|---|
| **3**（R111） | **−17.5%**（n.s.） | −0.0% |
| **9**（R112） | −2.2% | **+13.1%**（t=2.11, borderline） |
| **15**（R114） | **−3.2%（n.s.）** | **+5.4%（n.s.）** |

- **两次"大效应"（n=3 −17.5%；n=9 +13.1%）在扩样后均塌缩** → **纯小样本波动**；
- **n=15 判定：TOU 对峰段/总额量均无显著效应**（t 皆 |·|<1）。

## 5. token 消耗（估算）

- 12 个 run × 4 步 ≈ **48 次调用**（本轮）；累计 TOU **120 call**。

## 7. 结论

**TOU = null（n=15 充分功效下：峰段 −3.2%、总电量 +5.4%，均不显著）**。
这是"**小样本假象**"的第二次决定性演示，与 R104 漂移红线共同构成方法学核心。
