# R118 — 新事件 `ac_tax`（热浪+空调峰税）：**显著降低空调与峰段负荷**（定稿）

- **轮次**：Round 118
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_838587 h002M1；**交错** heatwave×15 + (heatwave+ac_tax)×15；~96 calls）
- **结论**：✅ **新稳健发现**：ac_tax 使 **AC 启用 15/15 → 7/15（Fisher 双侧 p≈0.0022）**，峰段 **−22.5%（p≈0.033）**

---

## 1. 目标

`ac_tax`（"evening-peak 空调 10% 税"）为**尚未测试**的结构性事件。检验其在热浪背景下
是否改变空调行为与峰段负荷（二值 + 连续，same-era 交错）。

## 2. 方法（可复现）

```powershell
foreach ($i in 1..15) {
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 `
    --env "hw_$i" --event-template "2026-09-11|heatwave" --workers 1
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 `
    --env "ha_$i" --event-template "2026-09-11|heatwave" --event-template "2026-09-11|ac_tax" --workers 1
}
```

## 3. 结果（n=15）

| 指标 | heatwave | heatwave+ac_tax | Δ | 配对 mean ± std | t(df=14) |
|---|---|---|---|---|---|
| **AC kWh** | 5.627 ± 2.135 | 2.600 ± 3.407 | **−53.8%** | −3.027 ± 3.868 | **−3.03**（p≈0.009） |
| **峰段(16–21) kWh** | 4.164 ± 1.307 | 3.225 ± 0.660 | **−22.5%** | −0.939 ± 1.540 | **−2.36**（p≈0.033） |
| 总电量 kWh | 14.268 ± 3.507 | 10.774 ± 4.230 | −24.5% | −3.494 ± 4.720 | −2.87（p≈0.012） |

- **二值（漂移免疫）**：AC 启用 heatwave **15/15** vs +ac_tax **7/15** → **Fisher 双侧 p≈0.0022**；
- 峰段 11/15 对更低；**漂移检验**：峰段–次序斜率 **−0.021 kWh/run**（同对相邻贡献 ≈−0.02，远小于 −0.94）。

## 4. 关键：通过 n=15 功效检验（对比 TOU）

| N | 峰段 Δ |
|---|---|
| 3 | −37.3%（n.s.） |
| 9 | −36.3%（t=−4.21） |
| **15** | **−22.5%（t=−2.36, p≈0.033）** |

峰段效应随 n 增大**收缩但仍显著**——这是**真实效应**的特征（对比 TOU：−17.5%→+13.1%→−3.2%，塌缩为 null）。
**二值信号（AC 15/15→7/15, p≈0.0022）为最强证据。**

## 5. 解读

- **事件类型边界修正**：`ac_tax` 是**结构性价格/税**事件，同时含"税+晚峰+空调"三重靶向，
  在热浪背景下**稳定改变设备行为**（关空调），与纯信息事件（storm/energy_crisis）不同；
- 与 `blackout_risk`/`price_hike`（撤回）**区别**：那两者是**跨时段连续伪影**；`ac_tax` 经 **same-era 交错 + n=15 + 漂移检验**成立；
- 与 `heatwave→AC`（R16）互补：热浪开启 AC，ac_tax 将其**部分关闭**（条件效应）。
