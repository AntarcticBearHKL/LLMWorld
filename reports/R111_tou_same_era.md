# R111 — same-era 交错重测：TOU 名义 −17.5% 削峰（n.s.，方向不再翻转）

- **轮次**：Round 111
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_838587 h002M1；**交错** baseline×3 + tou×3，同批次；~24 calls）
- **结论**：⚠️ **名义削峰 −17.5%（方向稳定），但 n=3 不显著（t≈−1.39）**；总电量持平

---

## 1. 目标

TOU（旗舰 RQ2 干预）此前"**不可定论**"（方向随采样/推理模式翻转，R023/R026）。本轮用
**同批次交错**设计（规避 R104 跨时段漂移），给其**有效**评估。

## 2. 方法（可复现）

```powershell
foreach ($i in 1,2,3) {
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 --env "tb_$i" --workers 1
  python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 1 --env "tt_$i" --policy tou --workers 1
}
```

## 3. 结果（world_838587 h002M1，2026-09-11）

| 指标 | baseline (tb_1..3) | tou (tt_1..3) | Δ |
|---|---|---|---|
| 总电量 kWh | 8.565 / 8.996 / 6.851 → **8.137 ± 0.926** | 8.007 / 8.727 / 7.669 → **8.134 ± 0.441** | **−0.0%** |
| 日间 kWh | 0.649 / 1.062 / 0.649 → 0.787 | 1.062 / 0.649 / 0.649 → 0.787 | +0.0% |
| 峰段(16–21) kWh | 3.646 / 3.077 / 3.472 → **3.398 ± 0.238** | 2.058 / 3.259 / 3.098 → **2.805 ± 0.532** | **−17.5%** |

配对峰段差 = [−1.588, +0.182, −0.374] → mean **−0.593**，std 0.739，**t≈−1.39（n.s., p≈0.30）**。

## 4. 解读

- **方向稳定为削峰**（2/3 配对下降；与 R023/R026 的"方向翻转"不同——那些受**跨时段漂移**污染）；
- 名义幅度 **−17.5%**（远超 guide 的 −3~6% 与 in_home_display 的 −10.3%），但**仍 n.s.**：
  n=3、配对 std≈0.74 kWh → 需 **n≥15** 方能判 5% 水平；
- **总电量/日间持平**（−0.0%）：TOU 只**移峰不节能**，方向合理；
- **限制**：单成员、1 天；但设计**有效**（same-era 交错）。
