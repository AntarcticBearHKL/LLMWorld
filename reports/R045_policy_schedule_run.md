# R045 — `--policy-schedule` 真调：TOU 生效→移除的"习惯黏性"探针

- **轮次**：Round 45
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（house_0002 M1，4 天；TOU 生效 2 天→移除 2 天）
- **结论**：✅ 能力端到端可用；⚠️ 观察到**移除后峰段回弹**（弱习惯黏性），但**未做平行对照**

---

## 1. 目标

R027 恢复 `--policy-schedule` 并单测接线，但**未真调**。guide §7 的"公告-生效-移除/习惯黏性"实验
需要该能力。本轮做首个真调，检验：政策窗口内是否生效、移除后行为是否回弹。

## 2. 设计（可复现）

```powershell
python run.py --mode simulate --world world_838587 --house house_0002 --member 0 --days 4 `
  --env sched_run --policy-schedule "2026-09-11,2026-09-12,tou" --workers 1
```

- 日期 2026-09-11..14；TOU 生效 **09-11/12**，移除 **09-13/14**；
- 政策日输出带 `_tou` 后缀，非政策日为 baseline；
- 离线 `load_model.build_load_profile` 计算总电量与峰段(16–21) kWh。

## 3. 结果

**接线证据**（运行日志）：
```
[Policy] 2026-09-11: tou
[Policy] 2026-09-12: tou
[Policy] 2026-09-13: none
[Policy] 2026-09-14: none
```

| 日期 | 政策 | 总 kWh | 峰段 kWh | 峰 W |
|---|---|---|---|---|
| 09-11 | tou | 10.190 | 3.559 | 5519.1 |
| 09-12 | tou | 9.770 | 1.889 | 3121.1 |
| 09-13 | 无 | 10.277 | **4.002** | 3520.1 |
| 09-14 | 无 | 9.235 | **3.098** | 4319.1 |

**派生**：政策日均峰段 ≈ **2.724 kWh**；移除后均峰段 ≈ **3.550 kWh**（**+30%**）→ **回弹**。

## 4. 解读（保守）

- **能力正确**：时间线按窗口激活/移除（日志与文件后缀均证实）。
- **提示弱习惯黏性**：移除 TOU 后峰段回升 → 与"政策在时才削峰、撤去即回复"一致。
- **重要限制**：**无平行对照**（未跑同 4 天的纯 baseline），且**星期混叠**
  （政策日=周五/六，移除日=周日/一）；n=1。故**仅作方向性观察**，非因果结论。
