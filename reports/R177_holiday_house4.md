# R177 — 假日跨住户 #4（world_143345 **h003**，AC 主导 3 口）：**总 +64.5%（p=2e-4）**

- **轮次**：Round 177
- **日期**：2026-09-12
- **验证层级**：**L2 真调**（world_143345 **house_0003**（3 口，AC 占峰 28%）M1；baseline×15 + `holiday`×15；~120 calls）
- **结论**：✅ **跨住户复现（第 6 户）**：总电量 **+64.5%（t=+4.93, p=2.0e-4）**；峰段 **+96.4%（p=3e-5）**
  → holiday **总量效应 6/6 住户显著**（含 AC 主导户）。

---

## 1. 目的

补 **AC 主导**住户（world_143345 h003，AC 占峰 28%），检验假日效应是否随峰段构成改变。

## 2. 方法（可复现）

```powershell
foreach ($i in 1..15) {
  python run.py --mode simulate --world world_143345 --house house_0003 --member 0 --date 2026-09-11 --env "hol3h3_b_$i" --workers 1
  python run.py --mode simulate --world world_143345 --house house_0003 --member 0 --date 2026-09-11 --env "hol3h3_h_$i" --event-template "2026-09-11|holiday" --workers 1
}
python src/analyze/compare_cpp.py --world world_143345 --house house_0003 --date 2026-09-11 --base-prefix hol3h3_b --treat-prefix hol3h3_h --n 15 --tag baseline
```

## 5. 解读

1. **总量 6/6 住户显著正向**（+20.8%~+64.5%）→ holiday 是**最稳健**的事件效应之一；
2. **峰效应仍住户相关**（+7.8%~+232%）：假日使居家日间/晚峰活动增加，净峰取决于基线作息与设备构成；
3. **含 AC 主导户**（h003）总量仍 +64.5% → 假日效应**不依赖**峰段是否 AC 主导。
