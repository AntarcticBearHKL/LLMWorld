# R162 — CPP 时段再分配（0 token）：**纯节能，非移峰**（谷期未升）

- **轮次**：Round 162
- **日期**：2026-09-12
- **验证层级**：**L0 分析**（复用 R161 的 45 个 env 产物；**0 token**）
- **结论**：CPP 总量 −14.4%，但**峰段 −2.7% n.s.、谷期 −6.0% n.s.**（谷期**下降**而非上升）
  → **CPP 是"全时段节能"，不是"移峰"**；与 TOU（峰↓谷↑ 的移峰模式）形成对照。

## 1. 目的

R161 发现 CPP 总量显著降（−14.4%）但不削峰（−2.7%）。关键机制问题：降下来的电是**移到了谷期**（shift）
还是**根本没被使用**（conservation）？用谷期（22:00–07:00）指标 + 分时分解回答。

## 3. 结果（n=15，配对 t，df=14）

| 时段 | baseline | cpp | Δ | t | 判读 |

| 总量 | 8.766 | 7.505 | **−14.4%** | −3.17 | **显著节能** |

对照 `cpp_soft`：总量 −10.9%，峰 −7.1%，**谷 −11.3%**（谷期降幅更大）。

## 4. 解读

- **谷期未升**（−6.0%）→ **无负载转移（无 valley filling）**；减少量分布在峰、谷、肩段全域；
- → **CPP = 价格→"少用"，而非"挪走"**；与 **TOU 的移峰模式**（峰↓、谷↑，据 Faruqui）方向不同；
- 结合 R161：CPP 既**不削峰**也**不移峰** → 该住户（烹饪主导，R151）对"通用高价"只做**总量保守**，
  与 **headline "节能 ≠ 削峰"** 一致；
- 机制补充：烹饪设备可替代（R144/R156），但 agents 未把负荷移到谷期，而是**整体削减**（炊具 −15.5%、
  壶 −46.9%），说明是"减少做饭/烧水"而非"改期做饭"。
