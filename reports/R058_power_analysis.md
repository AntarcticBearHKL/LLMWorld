# R058 — 功效/预算分析：该噪声下能检测多大的效应？

- **轮次**：Round 58（检查点；**0 token**）
- **日期**：2026-09-11
- **结论**：⚠️ **文献尺度的效应（~3%）在本平台噪声下不可行**；仅**大效应（≥10–20%）**可检测

---

## 1. 输入（R057 噪声地板）

同一配置 3 次运行：总量 **mean = 8.45 kWh，std = 1.01 kWh**（CV ≈ 12%）。

## 2. 方法

以两独立样本近似，每组所需运行数 `N ≈ (2.8·σ/Δ)²`（按 ~80% 功效、α=0.05 的粗估；Δ = 效应大小，kWh）。

## 3. 结果

| 目标效应（占均值） | Δ (kWh) | 所需 N / 组（粗估） |
|---|---|---|
| 3%（纯 TOU 文献基准） | 0.25 | **≈ 124** |
| 5% | 0.42 | ≈ 45 |
| 10% | 0.85 | ≈ 11 |
| 20% | 1.69 | ≈ 3 |
| 30% | 2.54 | ≈ 1.2 |

## 4. 解读（关键）

- **文献基准（−1~3%）不可达**：需 ~45–124 次运行/臂——远超 token 预算。
- **只能检测大效应**：10% 需 ~11 次/臂；20% 需 ~3 次/臂。
- 因此本平台**适合报告方向/定性/异质性**，**不适合报告与文献对齐的绝对幅度**；
  这与 R039/R047/R054/R057 的主线完全一致。
- **例外**：二进制/定性信号（热浪→AC on/off）效应量近乎 100%，少数样本即可判定。

## 5. 对论文的建议

1. **主打**：定性/方向 + 异质性（RQ1/RQ3）+ 事件驱动的二进制行为（RQ2）；
2. **幅度**：明确标注"本平台噪声地板 CV≈12%，文献尺度幅度不可判定"，将其作为**方法学贡献/局限**；
3. 若要幅度：为**大效应**干预设计 N≈3–10 的 campaign（用 `aggregate_runs` 报告 mean±std/SE），
   并在预算上说明。
