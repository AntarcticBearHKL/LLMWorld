# R174 — 假日跨住户复现（world_838587 **h001**）：总 +20.8%（p=0.006）；**峰值 +63.0% 显著**

- **轮次**：Round 174
- **日期**：2026-09-12
- **验证层级**：**L2 真调**（world_838587 **house_0001** M1（4 口）；baseline×15 + `holiday`×15；~120 calls）
- **结论**：✅ **跨住户复现**：总电量 **+20.8%（t=+3.21, p=0.0063）**；峰段 **+63.0%（t=+3.69, p=0.0024）**、
  谷期 **−46.1%（p=6.6e-5）** → 假日**总量上升**稳健（现跨 **4 个住户**）；**峰效应确认住户相关**。

---

## 1. 目的

holiday headline 此前每世界**单住户**（h002）。本轮用 **world_838587 h001（4 口之家）**补**同世界第 2 户**，
增强 cross-household 证据。

## 2. 方法（可复现）

```powershell
foreach ($i in 1..15) {
  python run.py --mode simulate --world world_838587 --house house_0001 --member 0 --date 2026-09-11 --env "holh1_b_$i" --workers 1
  python run.py --mode simulate --world world_838587 --house house_0001 --member 0 --date 2026-09-11 --env "holh1_h_$i" --event-template "2026-09-11|holiday" --workers 1
}
python src/analyze/compare_cpp.py --world world_838587 --house house_0001 --date 2026-09-11 --base-prefix holh1_b --treat-prefix holh1_h --n 15 --tag baseline
```

## 3. 结果（n=15）

| 指标 | baseline | holiday | Δ | t | p |

| **总电量** | 9.150 | 11.049 | **+20.8%** | **+3.21** | **0.0063** |

## 4. 解读

1. **总量效应跨住户复现**（+20.8%）：假日 headline 现 **4 个住户**（W1h002 +48.3%、W1h001 +20.8%、
   W2h002 +31.9%、W3h002 +39.8%）→ **全部显著正向**；
2. **峰效应确认住户相关**：h001 峰 **+63.0%（显著）**，而 h002 +7.8%（n.s.）；三世界方向 +/+/− →
   进一步支持"**峰不作断言**、只断言总量"；
3. **时段前移在 h001 更强**：谷期 −46.1% → 4 口之家假日白天居家使晚峰/夜间大幅前移（与 R170 一致）。
