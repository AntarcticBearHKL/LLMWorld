# R104 — 重大 validity 修正：基线跨时段漂移 → 连续"削峰"结论是**伪影**

- **轮次**：Round 104
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（fresh baseline×3 + neutral event；~16 calls）
- **结论**：🚨 **撤回** blackout_risk/price_hike 等**连续削峰**结论（伪影）；**保留** 二值结论（热浪/寒潮/封锁）

---

## 1. 触发

R094/R096/R103 显示多个事件"削峰"（blackout_risk −20~−32% 等）。但**屏幕**（R104 起）发现
**连 `solar_incentive`（光伏补贴，本不应影响用电）也削峰 −19.9%**——异常。

## 2. 决定性检验

- **中性事件**（“routine notice，无任何指令”）：峰段 **3.145（−32.9%）** —— 也"削峰"；
- **全新 baseline**（同配置、同日、刚跑 ×3）：峰段 **[3.472, 3.098, 3.753]，mean 3.441**；
- **旧 baseline**（tou_ctl/sched_ctl/world_838587）：峰段 **[4.892, 4.645, 4.521]，mean 4.686**。

→ **事件运行与 fresh baseline 同区间；“旧 baseline”才是异常高**。所谓"事件削峰"是**拿错基线**造成的伪影。

## 3. 关键判别：二值 vs 连续

| 指标 | 旧 baseline | fresh baseline | 事件 | 结论 |
|---|---|---|---|---|
| **峰段 kWh（连续）** | 4.686 | 3.441 | 2.9–3.8 | ❌ **漂移敏感**（旧/新差 36%） |
| **总电量（连续）** | 8.454 | 8.957 | ~7–10 | 大体一致 |
| **AC/heating 启用（二值）** | 0 / 0 | 0 / 0 | heatwave 7.2 / cold 10.2 | ✅ **漂移免疫** |

- **二值结论稳健**：旧、新 baseline 的 AC/heating **都=0**，事件为 >0 → **热浪/寒潮/封锁结论成立**；
- **连续峰段/总电量敏感**：跨时段基线会**系统性漂移**（LLM 行为或环境随**会话时段**变化）。

## 4. 更正

- **撤回**：`blackout_risk` / `price_hike` 及其它事件的**连续"削峰"**结论（伪影）；
- **保留**：**二值事件结论**（热浪→空调 0/9 vs 11/12；寒潮→采暖 0/10 vs 6/10；封锁→外出 13/13→1/13）；
- **加强方法学**：**跨时段比较连续指标无效**——须**同一批次紧邻跑 baseline 与处理**，或只用**二值/结构**指标。

## 7. 结论

这是本工作**最重要的方法学发现之一**：LLM 代理的**连续行为指标跨会话时段会系统性漂移**，
使跨时段基线比较产生大规模伪影。**二值/结构指标**（设备开/关、外出/居家）**漂移免疫**，是唯一可靠类型。
