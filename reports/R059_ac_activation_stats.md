# R059 — 热浪"空调启用"二进制统计：baseline 0/4 vs heatwave 6/7（p≈0.015）

- **轮次**：Round 59
- **日期**：2026-09-11
- **验证层级**：L0（汇总既有真实运行产物；**0 token**）
- **结论**：✅ **强二值结果**：baseline 空调启用 **0/4**，heatwave **6/7**（Fisher 单侧 p≈0.015）

---

## 1. 目标

R058 功效分析指出：连续幅度在 CV≈12% 噪声下多不可判，但**二进制/大效应**可判。
本轮把已有的 baseline / heatwave 运行汇总为**空调启用率**（仅用 R15 天气联动后的热浪运行）。

## 2. 方法（0 token，复用既有产物）

对每个 (env, house, member, date) 用 `load_model` 计算 `AirConditioner` 分项 kWh，**>0 记为启用**。

## 3. 结果

| 运行 | AC kWh | 启用 |
|---|---|---|
| baseline h002 M1 | 0.000 | ✗ |
| baseline h001 M1 | 0.000 | ✗ |
| baseline h001 M2 | 0.000 | ✗ |
| baseline h001 M3 | 0.000 | ✗ |
| heatwave h002 M1 09-11 | 7.200 | ✓ |
| heatwave h002 M1 09-12 | 1.800 | ✓ |
| heatwave h002 M1 10-17 | 7.200 | ✓ |
| heatwave h002 M1 10-18 | 2.400 | ✓ |
| heatwave h001 M1 | 3.600 | ✓ |
| heatwave h001 M2 | 1.500 | ✓ |
| heatwave h001 M3 | 0.000 | ✗ |

**启用率**：baseline **0/4**；heatwave **6/7**。

**Fisher 精确检验**（2×2：baseline 0/4 vs heatwave 6/7）：**单侧 p ≈ 0.015**（双侧 ≈ 0.03）。

## 4. 解读

- **跨越噪声地板**：二进制启用率的效应量接近 100%，因此在 CV≈12% 的连续噪声下**仍显著**——
  这正是 R058 预测的"只有大效应可检测"的正例。
- **方向一致且稳健**：2 住户、多日期窗口；baseline 从不启用，heatwave 多数启用。
- **个体异质性**：h001 M3（heatwave）未启用（1/7）→ 与 RQ3 异质性叙事一致。
