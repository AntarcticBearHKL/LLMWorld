# R093 — 寒潮扩样达标：采暖启用 0/10 vs 6/10（**双侧 p≈0.011**）

- **轮次**：Round 93
- **日期**：2026-09-11
- **验证层级**：**L2 真实运行**（world_143345 house_0002 cold_snap；baseline 复用；~8 calls）
- **结论**：✅ **达到双侧显著**：baseline 采暖 **0/10** vs cold_snap **6/10**，Fisher **双侧 p ≈ 0.0108**

---

## 1. 目标（B1）

寒潮此前为**单侧**边缘（0/8 vs 4/8；单侧 0.038 / 双侧 0.077，R072）。本轮在 `world_143345` house_0002
（**基线采暖=0/0，干净**）补 2 个样本，力争推过**双侧 0.05**。

## 2. 设计（可复现）

```powershell
# baseline: world_143345 house_0002 (既有, 2026-09-11, 采暖=0)
python run.py --mode simulate --world world_143345 --house house_0002 --days 1 `
  --env w143_h2_cold --event-template "2026-09-11|cold_snap" --workers 2
```

采暖 = `SpaceHeater + AirConditioner` 分项 kWh（>0 记为启用）。

## 3. 结果（跨 3 世界累计）

| 世界 | baseline 采暖>0 | cold_snap 采暖>0 |
|---|---|---|
| world_838587 | 0/1 | 1/1 |
| world_172148 | 0/7 | 3/7 |
| **world_143345** | **0/2** | **2/2**（12.2 / 1.5 kWh） |
| **合计** | **0/10** | **6/10** |

**Fisher 精确检验（0/10 vs 6/10）：双侧 p ≈ 0.0108 → 显著（p<0.05）。**

## 4. 解读

- **从单侧边缘升为双侧显著**：新增 2 个干净样本均启用，p 由 0.077 降至 **0.011**；
- 与 R084（world_143345 house_0001 配对 null）的差异：那里**基线已采暖**（污染），
  而 house_0002 **基线为 0**，故为干净对照——再次印证 R082「**基线世界/住户特异**」；
- 启用率 **6/10（60%）**，仍低于热浪（11/12≈92%）——**不同事件稳健性不同**。

## 5. token 消耗（估算）

- 1 个 cold_snap run × (4 步 × 2 成员 × 1 天) ≈ **8 次调用**。

**寒潮→采暖**现亦为**跨 3 世界、双侧显著**（p≈0.011）。本工作现有**三个**统计显著的事件结论。
