# 计划40:负荷曲线聚类与行为分组(家庭负荷聚类工具)

## 做什么

为 LLMWorld 增加"负荷曲线聚类"分析能力:读取世界内各家庭某场景某日的
1440 分钟负荷曲线,提取 24 小时形状特征,用自实现 K-means 聚类,
输出每簇典型曲线、每户簇标签与簇级特征,并在前端展示。

## 为什么(论文依据)

1. **Michalakopoulos et al. (2023), arXiv:2310.20367**
   《A Machine Learning-Based Framework for Clustering Residential
   Electricity Load Profiles to Enhance Demand Response Programs》
   伦敦 5000 户智能电表数据,对比 K-means/K-medoids/HAC/DBSCAN,
   最优 7 簇;结论:负荷形状聚类可支撑"定向需求响应"——先分群,再对
   不同群施加不同干预。本项目借鉴:对模拟世界的家庭负荷曲线聚类,
   验证 LLM 模拟是否自然涌现出可分的消费行为群(方法论意义)。
2. **Dent et al. (2014), arXiv:1409.1043**
   《Variability of Behaviour in Electricity Load Profile Clustering》
   用行为变异性聚类家庭,发现高变异性家庭对激励更敏感。
   本项目借鉴:聚类的同时输出每簇行为特征(峰时/峰均比/负荷率),
   为后续"按簇定向政策"实验铺路。
3. **Gunkel et al. (2022), arXiv:2210.03524** (DTU)
   《Variability in electricity consumption by category of consumer》
   不同消费者类别负荷分布特征差异显著(热泵 vs EV 峰时贡献不同)。
   本项目借鉴:聚类特征选择"形状优先"(归一化),类别差异不看量级看形态。

## 怎么做

1. `Implement/engine/load_features.py`(纯逻辑,零 LLM):
   - `hourly_means(profile_watts)`:1440 分钟 → 24 小时均值
   - `normalize_shape(hourly)`:除以总和 → 形状分布(去掉量级)
   - `load_factor(hourly)`:均值/峰值(负荷率)
   - `peak_hour` / `valley_hour` / `peak_to_mean`
   - `kmeans(features, k, seed, iters)`:**sklearn.cluster.KMeans**(k-means++ 初始化,
     n_init=10;§一.22 规则:成熟算法用库,不手写)
   - `elbow_scores(features, k_max)`:肘部法评估
2. `Implement/load_profile_cluster.py`(CLI):
   - 扫描 `outputs/<world>/<postcode>/<house_id>/<scenario>/<date>/用电信息/house_load_profile_1440min.json`
   - 特征:24h 小时均值 + 形状归一化
   - `--k` 缺省用肘部法自动选(2..min(8, 户数-1))
   - 输出 `outputs/<world>/analysis/clusters_<scenario>_<date>.json`:
     每簇:户列表/中心曲线/平均峰时/平均负荷率;每户:标签+特征;WCSS 肘部
3. `server.py`:`GET /api/worlds/<id>/clusters/<scenario>/<date>`
4. 前端:新增"负荷曲线聚类"面板——每簇一个小 canvas 画中心曲线
   + 簇特征表 + 簇内家庭列表
5. `test_offline.py`:合成可分离数据验证 kmeans 还原、特征计算、
   肘部单调性、空输入边界

## 怎么验证

- `python Implement/test_offline.py` 全绿(新增 TestLoadFeatures + TestClustering)
- 手工造 3 组不同形状曲线跑 `load_profile_cluster.py` 验证输出正确
- server `--query` 或 curl 验证新端点
