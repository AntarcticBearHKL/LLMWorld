# 计划 4 —— 人口级并行模拟（RQ1 里程碑）

> 依据：`StepInfo/00_需求与规则.md`（已重读）。数据围绕 Clayton 3168。

## 为什么做这步

论文 RQ1 的核心是"数百至数千户异质家庭的并行模拟 + 聚合负荷涌现"。目前系统只能一单一家庭模拟。本步打通：
1. **人口构建**：用 Clayton 3168 的 census 统计（中位年龄 28、住宅 7150 套、家庭构成）本地确定性生成 N 户异质家庭（0 LLM 调用、0 token、种子可复现）
2. **并行执行**：多家庭逐日并行模拟
3. **聚合产出**：人口级 1440 分钟负荷曲线 + 群体统计（均值/中位/分位/分散度）

## 做什么

| # | 任务 | 文件 | 验收 |
|---|---|---|---|
| 1 | 全局并发硬保险：SubAgent 加全局信号量，任何时刻真实 API 并发 ≤10（多家庭并行也不破限） | `subagent.py` | 测试：并发峰值 ≤10 |
| 2 | 人口构建器：census 校准的 4 类家庭模板（年轻夫妇/有孩家庭/独居/合租），本地确定性生成 N 户 | 新建 `Implement/population.py` | 同种子两次生成完全一致；家庭数/类型分布符合要求 |
| 3 | 人口并行 runner：逐日、逐户并行模拟 + 聚合输出 | 新建 `Implement/population_runner.py` | 输出 population 级 1440 点曲线 + 统计 |
| 4 | 离线测试：构建器确定性、聚合数学 | `test_offline.py` 扩展 | 全绿 |
| 5 | 真实运行验证：4 户 × 1 天（Clayton 3168），检查成本与聚合结果 | 运行 | 聚合曲线合理、token 账单、无并发超限 |

## 设计（保持可读）

```
population.py（人口构建器，0 LLM）
  POPULATION_TEMPLATES = { 4 类家庭模板（参照 census: 中位年龄28、家庭构成）}
  build_population(world_id, count, seed)
    → 写 worlds/<world_id>/3168/house_XXXX/household.json（与生成世界同构）

population_runner.py（并行执行）
  for day in days:
      ThreadPoolExecutor(≤5 户并行) 并行 simulate_day
      → 聚合所有户 1440 分钟曲线 → outputs/<world>/population/<date>.json
  SubAgent 全局信号量保证 API 并发 ≤10（跨户叠加也不破限）
```

## 怎么验证

1. `test_offline.py` 全绿（新增：构建器确定性 + 聚合）
2. `python Implement/population_runner.py pop01 --days 1`（先 build_population 4 户）→ 输出聚合曲线，检查：
   - 人口总 kWh ≈ Σ 各户
   - 每户曲线互异（异质性存在）
   - token 账单合理（4 户 ≈ 4×单户）
3. git 提交

## 学术依据

- **Piao et al. (2025) AgentSociety**：1 万+ 智能体城市级模拟 → 本步的多户并行 + 聚合是"城市级"的雏形
- **Schröder et al. (2013)**：家庭构成对能耗影响显著（规模经济）→ 模板库按家庭类型差异构建，天然支持该实证
- **Costa & Kahn (2010)**：异质性家庭对同一信号响应不同 → 构建器保留"意识形态/节能意识"参数（energy_awareness），为干预实验铺路
