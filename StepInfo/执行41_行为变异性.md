# 执行41:跨日行为变异性分析

## 实际做了什么

1. **论文搜索(第二轮持续开发)**:
   - arXiv API 限速(429)→ 改用 arXiv search UI
   - 搜索 "residential electricity load variability flexibility" → 7 篇结果
   - 选定 2 篇新依据 + 复用 Dent 2014(计划40已引)
2. **`engine/load_features.py` 新增 4 个变异性指标**(零注释):
   - `hourly_cv_curve`:24 维逐小时跨日变异系数(mean=0 安全处理)
   - `variability_index`:逐小时 CV 均值(0=完全规律)
   - `peak_hour_shift`:每日峰时样本标准差(漂移量,小时)
   - `daily_kwh_cv`:日总用电变异系数
3. **新增 `Implement/analyze_variability.py`**(CLI):
   - 扫描世界某场景下每户全部日期曲线(多日)
   - 每户:变异指数/峰时漂移/日kWh CV/逐小时CV曲线/日kWh序列
   - 按变异指数排序 + 高/低变异性对半分组
   - 输出 `outputs/<world>/analysis/variability_<scenario>.json`
4. **`server.py`**:`load_variability` + `GET /api/worlds/<id>/variability/<scenario>`
5. **前端**:新增"行为变异性"面板——每户变异指数条形图(canvas 已有多图,
   本次用 div 条形)+ 高/低变异性分组列表
6. **测试**:TestVariability 6 项 → 总 96 项全绿(skipped=5)
