# 执行47:峰值叠加检测(需量电价配套验证)

## 实际做了什么

1. **论文依据**:Thorvaldsen et al. 2021 (arXiv:2105.11952,
   需量电价计费基础=最高小时负荷)+ Alexeenko & Bitar 2023
   (arXiv:2112.04559,EV 充电叠加削减)——叠加事件是
   peak_demand/ev_delay 政策的直接响应度量
2. **`engine/load_features.py` 新增**:
   - `peak_overlap_events(watts, threshold=8000)`:扫描连续 ≥8kW 分钟段,
     输出事件[{start/end_minute, start/end_time, peak_watts, duration}]
   - `peak_overlap_count` / `peak_overlap_minutes`
3. **`engine/energy_calculator.py`**:
   - 导入 peak_overlap_events;`__init__` 加 `self.peak_overlap_events=[]`
   - `_finalize_statistics` 计算叠加事件
   - `总用电汇总.json` 加 `peak_overlap_events` 字段(向后兼容)
4. **前端**:houseDetail 追加"峰值叠加事件"表(开始/结束/峰值/时长)
5. **测试**:TestPeakOverlap 5 项(单事件/双事件/阈值边界/计数/
   summary 集成)→ 117 项全绿

## 结果

- `test_offline.py`:117 项 OK(skipped=5)
- 验证:8:30-9:30 段 8500W → 1 事件(start 08:30, 60 分钟, 峰值 8500W);
  分离两段 → 2 事件;7999W < 8kW → 0 事件
- server 重启完成
