# 计划95:世界删除(前端清理功能)

## 做什么

前端世界下拉旁加"删除世界"按钮 + server
`POST /api/worlds/delete/<id>`:删除 worlds/<id> 与
outputs/<id>(含聚合/分析/日志产物),有运行中任务时拒绝。
用户手工模拟模式下世界堆积后的清理入口。

## 为什么(依据)

1. **运维经验(§一.21)**:用户可一键创建世界(计划77)与
   批量模拟,但没有删除入口;世界+outputs 会长期堆积
   (计划36 曾命令行清理过时世界)。
2. **§一.15 精确清理**:删除按世界 ID 精确,不宽泛匹配。

## 怎么做

1. `server.py`:
   - `POST /api/worlds/delete/<world_id>`:
     - 校验 ID 合法且目录存在
     - 检查 /api/jobs 有该世界的 running 任务 → 拒绝
     - shutil.rmtree(worlds/<id>) + outputs/<id>
     - 返回 {"deleted": [...]}
2. 前端:工具栏"删除世界"按钮(confirm 二次确认)
   → 成功后刷新世界列表
3. 测试:TestSimArgs 风格——校验函数(非法 ID/不存在)
   [不真删,纯校验]

## 怎么验证

- `python Implement/test_offline.py` 全绿
- server restart + 冒烟(创建→删除测试世界)
