# 计划46:分析工具链一键化(make_analysis_all.py)

## 做什么

新增 `Implement/make_analysis_all.py`:一条命令跑完计划40-45的全部
分析工具(聚类/变异性/行为模式/人口归因/分组响应/政策矩阵),
自动扫描世界场景与日期,输出汇总。消除手工逐个调用的碎片化。

## 为什么(依据 + 思考过程)

1. **运维经验(§一.21 允许来源)**:计划40-45 累计 6 个分析工具,
   各自独立 CLI,手工逐次调用易漏、易错场景/日期参数;
   整合为一次运行,是"分析闭环最后一公里"。
2. **Fidone, Passaro & Guidotti (2025), arXiv:2511.07204 (AAAI 2026)**
   《Evaluating Online Moderation Via LLM-Powered Counterfactual
   Simulations》:LLM-ABM 中"并行反事实模拟 + 系统性评估"是方法学
   标配;其评估工作流(多干预并排对比)与本项目 policy_matrix/
   groups 体系一致——一键化让该工作流可复现执行。
3. 每个子工具已有论文依据(计划40-45),本步只整合不新增算法。

## 怎么做

1. `Implement/make_analysis_all.py`:
   - `--world` 必填;`--date` 可选(缺省取各场景最新日期)
   - 自动扫描 `outputs/<world>/population/` 的场景列表
   - 每场景执行:
     - analyze_population(归因,最新日期)
     - load_profile_cluster(聚类,指定日期)
     - analyze_variability(变异性,多日)
     - analyze_behavior_patterns(模式迁移,多日)
   - 全场景执行:
     - analyze_groups --label-source awareness
     - analyze_groups --label-source variability
     - compare_policies --all(矩阵)
   - 打印每步结果摘要(复用各工具 build 函数,不走子进程)
   - 单日数据时变异性/模式给出提示但正常输出(1 天=0 迁移)
2. 复用各工具 build/report 函数(不重复实现)
3. 测试:TestAnalysisAll——合成 outputs 结构,验证场景扫描与
   各 build 函数调用路径(轻量,不跑 LLM)
4. README 补充一键化用法

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成 outputs 结构 CLI 冒烟:全部 JSON 产物生成、汇总打印
