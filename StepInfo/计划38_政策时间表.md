# 计划 38 —— 政策时间表（政策按日期在连续时间线上生效/失效）

> 依据：`StepInfo/00_需求与规则.md`（已重读：只计划→执行→修正，不主动模拟）。

## 为什么
连续时间线模拟中，政策应在特定日期自然施加/解除（如 TOU 从 04-25 开始、04-28 结束）。当前 `--policy` 只支持"全程生效"。加入**政策时间表**：`--policy-schedule "start,end,name"` 可多次，每日模拟按当天日期自动选择生效政策。

## 设计

```
runner 新参数：
  --policy-schedule "2026-04-25,2026-04-28,tou"   (可多次)
  --policy-schedule "2026-04-29,,nudge_loss"       (空结束=永久)

每日解析：按当天日期匹配区间 [start, end]（含端点）→ 生效政策
  - 多区间同日 → 报错提示
  - 无匹配 → baseline（无政策）
  - 与 --policy 互斥（同时给出报错）

聚合输出记录 policy_schedule 字段
```
