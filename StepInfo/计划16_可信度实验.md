# 计划 16 —— 新闻可信度实验（政府/媒体 vs 社交媒体谣言）

> 依据：`StepInfo/00_需求与规则.md`（已重读）。

## 为什么做这步

计划14 的 war_news 用的是官方公告+新闻媒体（可信来源）。真实社会里同一信息经不同渠道传播，信任度不同（谣言 vs 官方）。本步做**来源对照实验**：同样的战争/能源信息，来源换成"社交媒体（未经证实）"，对比 war_news → 信任异质性。

## 谣言版设计（与 war_news 唯一差异：来源+措辞）

war_news 版（已跑）：
- "新闻媒体：中东冲突升级，天然气期货单日上涨 15%，电费下月上调，专家呼吁节约"

rumor 版（本轮）：
- "社交媒体：有网友发帖称'中东打仗了，下周电费要暴涨，赶紧囤电'，该消息未经任何官方证实，能源局未回应"

预期：谣言版响应 < 官方版（信任度低 → 行为影响小），但个别"易受影响"家庭可能反而放大（恐慌囤电）——异质性即发现。

## 怎么验证
1. --no-events 单测/冒烟
2. rumor_news 运行成功 + 矩阵对比
3. 解读：rumor vs war_news 的峰值/总量差异
4. git 提交

## 学术依据
- 信息信任/来源可信度是行为经济学核心变量（信息框架文献）；社交媒体 vs 官方的信任差异在能源行为中已有实证（如智能电表信任研究）
- 呼应用户"上帝模式"愿景：同信息不同渠道 → 异质响应
