# 计划105:分析结果 CSV 导出

## 做什么

新增 `Implement/export_analysis_csv.py`:把 world 的 analysis/
目录下各 JSON 报告**导出为 CSV**(每工具一个文件,平铺每户
记录),便于 Excel/统计软件与论文表格制作。
覆盖:clusters/variability/anomalies/advice/behavior_load/
solar/appliance_usage/forecast/seasonal/weekday/world_summary。

## 为什么(依据)

1. **运维经验(§一.21)**:JSON 报告适合程序消费,论文写作/
   Excel 分析需要表格格式;20 个工具的 JSON→CSV 批量转换
   是研究数据处理的最后一公里。
2. **§一.3 学术导向**:论文数据表格化是写作基础。

## 怎么做

1. `Implement/export_analysis_csv.py`:
   - 遍历 outputs/<world>/analysis/*.json
   - 每文件按 per_house(或同构记录)平铺为 CSV 行
   - 输出 outputs/<world>/analysis/csv/<name>.csv
   - 控制台打印导出清单
2. 测试:TestExportCsv——合成 JSON 转 CSV 行数/表头正确、
   空目录容错

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成数据 CLI 冒烟
