# 计划 26 —— 多世界联合聚合（10 户/世界上限下的更大人口）

> 依据：`StepInfo/00_需求与规则.md`（归档补写，实现见执行26）。

## 为什么
用户 2026-08 指令"每世界最多 10 户"。要 20/30 户人口 → 多世界独立模拟后合并（0 token 纯聚合）。

## 设计
```
combine_worlds.py --worlds pop02 pop03 --scenario baseline --date 2026-04-21
→ outputs/combined_pop02+pop03/population/<scenario>/<date>/population_profile_1440min.json
  - 1440min 曲线逐元素求和
  - per_house 带世界前缀（pop02:house_0001）
  - 统计重算（总/户均/中位/峰值）
server 虚拟世界：list_worlds 扫描 outputs/ 下无 worlds/ 对应目录的 population 实体 → 前端可看
```

## 验证
- 22 户（10+12）：总 319.21 kWh、户均 14.51、峰值 58,450W@18:00
- 62 测试全绿（combine 数学/前缀/1440 点）
