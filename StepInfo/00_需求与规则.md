## 一、用户原始要求（2026-08 会话确立，持续有效）

1. **持续开发**：一直重复地开发下去，直到用户手工终止进程。永远不要停。
2. **代码可读性**：所有代码架构逻辑清晰，不懂代码的人也能一眼看懂。分层明确、命名直白、中文注释鼓励、单一职责。
3. **学术导向**：尽可能去任何论文网站（arXiv/Google Scholar/ACM/IEEE）搜索想法并合理应用；执行记录中注明论文出处（名/作者/年）与应用原理。
4. **API 约束（已按 2026-08 最新指令更新）**：
   - 只使用项目已有的 DeepSeek API 做测试（.env 的 DEEPSEEK_APIKEY）
   - 【最新】API 并行请求**不设任何上限**；户级并行多少只取决于世界有多少家庭（population_runner 的 ThreadPoolExecutor = len(worlds)）
   - 【世界级约束】每个世界**最多 10 户**（population.build_population 校验，超限抛 ValueError）
   - 重试机制保留（3 次指数退避）；并发峰值仅作观测（SubAgent.get_concurrency_stats），不做限制
   - 历史遗留：早期曾要求并发 ≤10（全局信号量）——**已作废**，但旧运行日志（job_001）中的"峰值 10"是旧代码输出，不代表现状
5. **数据约束**：使用的数据尽可能围绕 **3168 / Clayton**（墨尔本）；数据文件统一在 `Data/` 目录（census CSV、vic_electricity_data.csv、工具脚本 Data/tools/）
6. **开发节奏**：走一步看结果 → 没问题再规划下一步 → 执行。每步必须有"验证"环节（能跑就真跑，不能跑说明原因）。永远保留改进空间。
7. **记录要求**：`StepInfo/计划N_*.md` + `执行N_*.md` 持续记录（计划写"做什么/为什么/怎么做/怎么验证"，执行写"实际做了什么/结果/偏差/下一步候选"）。
8. **改动边界**：**只允许在 LLMWorld/ 内创建/修改文件**；每步执行完必须 git 提交同步。
9. **后台工作流模式（2026-08 最新指令，替代旧式阻塞等待）**：
   - 模拟任务放后台：`Implement/background_runner.py start <world> <args...>`（Popen 子进程 + logs/jobs/job_NNN.out）
   - **subagent 负责启动并监听模拟**（Task 工具派 general agent：轮询 `background_runner.py status`，最多等 40 分钟，完成后汇报聚合结果/token/警告）
   - **主 agent 在 subagent 监听期间持续开发**，累积变更（与模拟不冲突：模拟进程已加载代码到内存，改文件不影响运行中进程）
   - subagent 返回结果后：主 agent 根据结果追加变更（分析/报告/前端）
   - 最后把**等待期间累积的全部变更**交给新的 subagent 统一测试（跑 test_offline 等）
   - **禁止用 Start-Sleep 空转阻塞主线程**
10. **前端同步**：`Implement/frontend/index.html`（浏览器）+ `Implement/server.py`（常驻后端，HTTP API + CLI 查询）——**每一步新功能必须同步更新到前端展示**；界面实用清晰即可，不追求美观。
11. **环境信息接口**：天气/气温等 → `engine/environment_interface.py` 三模式（`config.ENV_MODE`）：real（真实 API，失败回退 config）/ config（墨尔本气候表按季节随机，种子可复现）/ manual（`Implement/env_manual.json` 固定值或范围）。

**论文级发现汇总**（可写论文的核心结果）：
1. TOU 削峰 -31~37%（晚峰时段用电 -9~-29%），峰值时刻稳定移至 22:30
2. 损失框架 nudge 是唯一总量下降场景（-5.5%，Ghesla 2019 对照）
3. 新闻（战争+税收）削峰 -29.2% ≈ 价格工具（信息即政策）
4. 高节能意识家庭响应 -15.7% vs 低意识 +5.2%（Costa & Kahn 2010）
5. 峰段价格弹性 ≈ -0.161（文献区间内，Wang et al. 2021 方向）
6. 峰均比随 N 收敛（4.83→2.52），10 户仍高于真实 1.2（规模论证）
