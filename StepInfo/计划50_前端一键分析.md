# 计划50:前端一键分析(上帝控制台增强)

## 做什么

前端上帝剧本面板增加"一键分析"按钮:浏览器中直接对当前世界
执行 make_analysis_all(聚类/变异性/模式/归因/分组/矩阵,
全部离线 0 token),完成后展示摘要并自动刷新各面板。
server 新增 `POST /api/worlds/<id>/analyze` 端点。

## 为什么(依据)

1. **运维经验(§一.21 允许)**:用户手工模拟模式(§一.19)下,
   分析要开终端逐条跑 6 个命令;前端一键化消除碎片化,
   且 §一.10 要求新功能同步到前端。
2. **Fidone et al. 2025 (arXiv:2511.07204, AAAI 2026)**
   (计划46已引):LLM-ABM 评估工作流应可一键复现;
   本轮把"一键复现"从 CLI 提到浏览器 UI。
3. 分析逻辑零新增(复用计划46 make_analysis_all),
   本步只加交互层。

## 怎么做

1. `server.py`:
   - `POST /api/worlds/<id>/analyze`:同步调用
     make_analysis_all.run_all(world_id) → 返回 {"ok", "summary": [...]}
     错误返回 {"error": ...}
2. 前端:上帝面板加"一键分析当前世界"按钮 + 结果区
   (点击后禁用按钮,完成后显示摘要并 refresh())
3. 测试:不新增(server HTTP 不易单测;run_all 已有冒烟
   + CLI 验证),保持 122 项全绿,重启 server 冒烟端点

## 怎么验证

- `python Implement/test_offline.py` 122 项全绿
- server restart 后 POST /api/worlds/<id>/analyze 冒烟
  (合成 outputs 世界 → 返回 summary)
