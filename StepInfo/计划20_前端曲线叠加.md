# 计划 20 —— 前端增强：多场景曲线叠加 + 多日能量轨迹

> 依据：`StepInfo/00_需求与规则.md`（已重读：每步新功能同步前端；界面实用清晰）。

## 为什么做这步

当前前端一次只看一个场景。研究者最需要的是**场景对比**（baseline vs tou vs war_news 同图）和**多日趋势**（同一世界多日的用电演化）。纯前端增强（canvas 多线绘制 + 柱状图），后端 API 已足够。

## 做什么

| # | 任务 | 文件 | 验收 |
|---|---|---|---|
| 1 | 曲线叠加：场景多选框 → 同 canvas 绘制多条 24h 曲线 + 图例 + 颜色区分 | `frontend/index.html` | 多场景同图可读 |
| 2 | 多日能量轨迹：世界级各场景每日总用电柱状图（跨日期） | `frontend/index.html` | 趋势可见 |
| 3 | 验证：起服务 → 前端逻辑（API 数据已备，无后端改动） | 运行 | 页面无 JS 错误 |
| 4 | git 提交 | | |

## 设计

- 场景区改为 checkbox 列表（默认勾选当前场景）→ 收集勾选场景 → 分别 fetch profile → 同 canvas 多线（每场景一色）
- 多日轨迹：遍历该世界所有场景的所有日期 → 柱状图（x=日期, y=总kWh, 场景分色）
- 保持单文件前端，结构清晰
