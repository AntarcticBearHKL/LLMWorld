# 计划77:前端新建世界(0 token 人口生成闭环)

## 做什么

前端"政策实验启动"面板加"新建世界"区:世界名输入 + 户数输入 +
"生成人口"(调 population.py,0 LLM 调用,Big Five+8 类家庭)
→ 刷新世界列表 → 用户即可开启模拟。
打通"新建世界→开启模拟→自动跟踪→一键分析"完整体验闭环
(00 规则 §七.6 一键体验,生成段完成)。

## 为什么(依据)

1. **运维经验(§一.21)**:程序化人口生成(population.py,计划22,
   0 LLM)一直只能命令行跑;用户手工模拟模式下
   "生成→模拟→分析"三环节中"生成"缺前端入口。
2. **计划22 论文基础**:Deep and diverse population synthesis
   (arXiv:2508.09964)等 12 篇(RefPaper 已存)——
   程序化生成 0 token,前端一键即得。

## 怎么做

1. `server.py`:
   - `POST /api/worlds/create` body={world_id, count, seed}:
     校验 world_id 不存在;调 population.py main 逻辑
     (subprocess 或 import 调用)
     → {"ok", "households": n}
2. 前端:新增"新建世界"区(名称/户数/生成按钮)→ 成功后
   刷新世界下拉并选中新世界
3. 测试:TestSimArgs 风格——create 端点参数校验(缺字段/
   重名拒绝),纯函数化可测

## 怎么验证

- `python Implement/test_offline.py` 全绿
- server restart + POST create 冒烟(生成后删除测试世界)
