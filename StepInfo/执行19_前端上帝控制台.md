# 执行 19 —— 前端上帝控制台 + 自动刷新

> 对应 `计划19_前端上帝控制台.md`。

## 实际做了什么
1. **server.py 支持 POST /api/worlds/<id>/events**：
   - `_read_json_body()` 读取 JSON body；缺 date/title/content 返回 400
   - `add_event_to_script()` 追加事件到 worlds/<id>/events.json（模拟中每天重读 → 实时生效）
2. **前端上帝控制台面板**：日期/标题/内容/来源输入 + 注入按钮 + 即时状态提示 + 新闻面板刷新
3. **10 秒自动轮询**：当前视图（曲线/矩阵/新闻/明细）自动刷新，模拟世界的变动实时可见
4. Design/Server.aas 更新（POST 接口）

## 验证结果
- POST 注入实测成功：事件数 4→5，随后 400 缺字段校验生效
- 47 项离线测试全绿
- **发现并处理**：PowerShell 发送中文 JSON body 会丢失字符（变 `????`）——这是测试工具编码限制，浏览器 fetch 原生 UTF-8 无此问题；残留测试事件已清理，剧本恢复 4 条

## 使用方式
- `python Implement/server.py` → 浏览器 http://localhost:8080
- 上帝控制台：选世界 → 填事件 → 注入 → 模拟运行中事件实时生效
