# 计划68:作息经验锚定(行为层 prompt 增强)

## 做什么

simulate_step1_macro_plan.md 模板加入**澳大利亚典型作息锚点**
(经验锚定,empirical grounding):工作日/周末的起床/用餐/通勤/
就寝典型时段表,并提示按职业与家庭角色调整。
让 LLM 计划生成的作息分布贴近实证人口行为,
而非完全自由生成。

## 为什么(论文依据 + 思考过程)

1. **Xia, Kuang & Hu (2026), arXiv:2607.17437**(RefPaper 已存):
   《Empirical Grounding Improves the Realism of LLM Agents》——
   把 ATUS(时间使用调查)基线嵌入 agent 初始化/提示词后,
   正常日活动分布相关性 0.528→0.912、MSE 0.066→0.008。
   → 思考:本项目 planner 第一步完全自由生成作息,负荷层
   验证相关性 0.71 已不错,但活动层无实证锚定;按论文方法
   在 prompt 中注入典型作息时段表,是保真度提升的最轻量落地
   (改模板文本,零代码逻辑变化)。
2. **计划22 已引 AToM Melbourne (arXiv:2112.12071)**:
   墨尔本合成人口+活动模式(Census 2016 + 维州出行调查)
   → 锚点按澳大利亚作息(晚餐 18-19 点早于北美)本地化。

## 怎么做

1. `prompts/simulate_step1_macro_plan.md`:
   - 新增"典型作息锚点(澳大利亚人口统计基准)"章节:
     工作日 6:30-7:30 起床 / 7-8 早餐 / 8-9 通勤 / 9-17 工作 /
     17-18 返家 / 18-19 晚餐 / 22:30-23:30 就寝;
     周末 7:30-9:00 起床、社交/家务/外出活动;
     并提示:按职业(上班族/学生/居家/轮班)、年龄、家庭成员
     调整,允许合理偏差,但作息高峰时段应与锚点一致
   - 保留全部现有 JSON 输出要求
2. 测试:TestPrompt 或新断言——模板渲染含"典型作息锚点"
   与"6:30"关键词(用 Prompt.load 渲染空参数验证静态文本)
3. 不改变 planner 代码(模板文本变更即生效)

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 模板渲染人工检查
