# 计划 24 —— 后台模拟工作流（放后台跑 + 进度监控 + 期间并行开发）

> 依据：`StepInfo/00_需求与规则.md`（已重读）+ 用户需求：模拟放后台等，先去写不需要等模拟的部分，统一放到下一次模拟时一起测试；用监控进程跟踪进度，完成或报错后立刻回来处理结果。

## 设计

```
Implement/background_runner.py（后台任务管理器）
  start <world> [模拟参数...]  → 启动子进程，输出重定向 logs/jobs/<job_id>.out
  status                        → 所有任务：状态/进度/耗时（从输出文件解析"第X/Y天"/"Token账单"/"冒烟通过/失败"）
  watch <job_id>                → 阻塞等待完成或失败（实时打印尾部进度）
  stop <job_id>                 → 终止进程
  任务元数据: logs/jobs/<job_id>.json（PID/命令行/状态/开始时间）
```

工作流（本步实战）：
1. `background_runner.py start pop03 --days 1` → 12 户 Big Five 人口基线放后台（~110 万 token）
2. **等待期间**：并行开发其他部分（本轮：README 工程文档 + Design 环境接口同步）
3. `watch` 监控 → 完成/报错 → 回来处理 pop03 结果（分析 Big Five 人格 → 用电多样性）
