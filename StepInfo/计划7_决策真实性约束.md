# 计划 7 —— 决策真实性约束：修复 EV 充电滥用等异常决策

> 依据：`StepInfo/00_需求与规则.md`（已重读）。

## 为什么做这步

计划6 发现 10 户模拟中 house_0010 达 107 kWh（户中位仅 12）——根因：LLM 让 7kW 电动汽车连续 charge_home 超 12 小时（≈87 kWh/天），不理解"充满即停"。这类决策让峰均比、相关性全部失真，**污染一切下游实验**（政策/事件对比都会带着这个噪声）。

## 硬上限设计（config.py）

```python
# 每电器每日最大使用分钟数（防止 LLM 决策不真实，如 EV 连续充 12 小时）
APPLIANCE_DAILY_CAP_MINUTES = {
    "电动汽车": 4 * 60,   # 充满约需 3-4 小时
    "热水器": 45,         # 每次洗澡 15-30 分钟
    "空调": 6 * 60,       # 一天最多连续开 6 小时
    "洗衣机": 2 * 60,
    "吸尘器": 60,
    "电视": 8 * 60,
    "电脑": 10 * 60,
    "电磁炉": 2 * 60,
    "微波炉": 60,
    "电饭煲": 2 * 60,
    "手机": 4 * 60,
    "灯": 16 * 60,
    "台灯": 16 * 60,
    "油烟机": 2 * 60,
}
```
- 超限部分截断，warning："电动汽车 已用 720 分钟，超过上限 240 分钟，截断"
- 截断基于**累计**（同一电器全天所有决策加总）

## 预期结果（假说）

- house_0010 类异常消失（EV ≤ 28 kWh/天 → 上限 4h×7kW = 28 kWh 封顶）
- 户均接近中位，std 下降
- 峰均比 2.52 → 进一步接近真实 1.2（合理幅度 ~1.5-2.5）
- 相关性 0.35 → 上升

## 学术依据

- 负荷建模文献普遍用**电器物理约束**限定使用（Richardson et al. 2010 的电器使用概率模型有明确时长分布；ARGOS/Capasso 1994 有设备功率谱）→ 本步把物理约束以"硬上限"形式注入
- **可信决策**是 SALM (Koley 2025) 强调的模拟保真前提

## 怎么验证

1. 单测：给 12 小时 EV 决策 → 截断为 4 小时 + 警告出现
2. 重跑 pop02 1 天 → 检查逐户 kWh 分布（无异常户）
3. 基线对比 pop02v2 → 指标对比表（修复前 vs 后）
4. git 提交
