# 计划99:政策权衡分析(policy trade-offs)

## 做什么

新增 `Implement/analyze_policy_tradeoffs.py`:从 policy_matrix.json
提取每政策的多维效果,输出**权衡矩阵**——每政策 ×
(总电变化%/晚峰变化%/峰值削减%/晚峰削减%/峰均比),
前端"政策权衡"面板直观比较政策间的取舍
(削峰 vs 节电 vs 错峰)。

## 为什么(论文依据 + 思考过程)

1. **CoRenew (2026), arXiv:2607.25447**(RefPaper 已存):
   LLM-ABM 政策平台显式支持 "compares policy performance across
   competing objectives" → 多目标权衡是政策评估标配。
2. **Faruqui & Sergici (2010)**(计划44已引):不同政策
   (TOU/CPP/IHD)在削峰与节能两个目标的组合不同
   → 权衡视图让"政策画像"一目了然。
3. **运维经验**:矩阵已有全部数据(compare_policies 产物),
   只缺"多目标并列"视图。

## 怎么做

1. `Implement/analyze_policy_tradeoffs.py`:
   - 读 outputs/<world>/comparison/policy_matrix.json
   - 每政策提取:total_change_pct / peak_hours_change_pct /
     peak_load_cut_pct / evening_change_pct / peak_to_mean
   - 输出 outputs/<world>/analysis/policy_tradeoffs.json
     (scenarios 数组:每政策各目标值;baseline 为基准)
2. `server.py`:`GET /api/worlds/<id>/policy-tradeoffs`
3. 前端:新增"政策权衡"面板(政策×目标表,负值绿/正值红)
4. 测试:TestPolicyTradeoffs——合成矩阵解析、
   缺文件容错

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成矩阵 CLI 冒烟
