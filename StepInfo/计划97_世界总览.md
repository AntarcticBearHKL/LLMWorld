# 计划97:世界总览(world_summary)

## 做什么

新增 `Implement/analyze_world_summary.py`:把各分析工具的
**关键指标聚合为每户总览表**——聚类簇/变异性组/异常数/
建议数/行为一致性/晚峰集中/光伏覆盖,一行一户,
前端"世界总览"面板一目了然。

## 为什么(依据)

1. **运维经验(§一.21)**:分析工具已达 17 个,每个产出独立
   JSON;用户想看"每户全貌"需跨 5+ 面板对照。
   总览=分析层的最终聚合(研究总览/报告入口)。
2. 各工具均有论文依据(计划40-93),本步零新算法,纯编排。

## 怎么做

1. `Implement/analyze_world_summary.py`:
   - 读 analysis/ 下 clusters_*/variability_*/anomalies_*/
     advice_*/behavior_load_*/solar_*/weekday_* 关键字段
   - 每户汇总:cluster / variability_group / anomaly_flags /
     advice_count / load_consistent / solar_coverage / mean_kwh
   - 输出 world_summary_<scenario>.json
2. `server.py`:`GET /api/worlds/<id>/world-summary/<scenario>`
3. 前端:新增"世界总览"面板(每户一行)
4. 测试:TestWorldSummary——合成各 JSON 汇总正确、
   缺文件容错、空数据报错

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成数据 CLI 冒烟
