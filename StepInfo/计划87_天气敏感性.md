# 计划87:天气敏感性分析(温度-用电关系)

## 做什么

新增 `Implement/analyze_weather_sensitivity.py`:从多日聚合
population JSON 提取 (温度, 日总用电) 对,计算:
- 温度-用电皮尔逊相关(正=夏季空调主导,负=冬季采暖主导)
- 线性斜率(kWh/°C,弹性度量)
- 按天气条件分组的日用电均值
输出报告 + 前端面板。验证 Jin 2021 主张
(温度是负荷变异最重要外部驱动)。

## 为什么(论文依据 + 思考过程)

1. **Jin et al. (2021), arXiv:2102.11027**(RefPaper 已存):
   夏季负荷形状变异的最重要外部驱动是户外温度
   (相对季节/星期)→ 温度-用电关系是"驱动强度"的量化。
2. **§一.11 环境信息接口**:模拟每日温度来自环境接口
   (population JSON 的 environment 字段,计划32 落盘)
   → 数据已在,只缺分析(运维经验)。
3. **弹性文献对照**:计划12 已算价格弹性;
   温度弹性(kWh/°C)是需求侧的互补度量。

## 怎么做

1. `Implement/analyze_weather_sensitivity.py`:
   - 扫描 outputs/<world>/population/<scenario>/*/ 的
     population_profile_1440min.json → (temperature, kwh) 对
     (temperature 取 environment 首户的 avg)
   - pearson 相关 + 线性斜率(最小二乘)
   - 按天气条件分组均值(kWh)
   - 输出 outputs/<world>/analysis/weather_<scenario>.json
2. `server.py`:`GET /api/worlds/<id>/weather/<scenario>`
3. 前端:新增"天气敏感性"面板(相关/斜率/按天气均值)
4. 测试:TestWeatherSensitivity——合成 (温度,kWh) 正相关/
   负相关/无数据

- `python Implement/test_offline.py` 全绿
- 合成数据 CLI 冒烟
