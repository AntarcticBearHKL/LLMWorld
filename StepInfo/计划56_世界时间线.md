# 计划56:世界时间线面板(政策/事件/用电 日期视图)

## 做什么

前端新增"世界时间线"面板 + server 新端点
`GET /api/worlds/<id>/timeline`:按日期汇总世界各场景的
**当日政策(day_policy)、新闻事件、总用电**,
一行一天,直观展示多日模拟中"发生了什么"。
收尾 00_需求与规则 §七.2 的"世界时间线面板"遗留项。

## 为什么(依据)

1. **运维经验(§一.21 允许)**:population JSON 已含 day_policy、
   events.json 已有事件日期、聚合 JSON 有每日 kWh——三者已在,
   缺的是汇总视图;多日模拟(policy-schedule/事件注入)后
   用户无法一眼看到"哪天生效什么政策/有什么事件/用电多少"。
2. **Fidone et al. (2025), arXiv:2511.07204 (AAAI 2026)**:
   评估工作流需要"干预发生时刻"的上下文视图
   (反事实对比的前提是知道何时施加了什么)。
3. **00 规则 §七.2** 明确遗留项。

## 怎么做

1. `server.py`:`load_timeline(world_id)`——扫描各场景各日期
   population JSON 的 day_policy/total_energy_kwh +
   events.json 事件 → [{date, scenario, policy, kwh, events[]}]
   端点 GET /api/worlds/<id>/timeline
2. 前端:新增"世界时间线"面板——表格(日期/场景/政策/总kWh/事件),
   政策变色标注、事件图标
3. 测试:TestTimelineServer——load_timeline 合成数据验证
   (日期合并/事件关联/缺字段容错)

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成 outputs+events 数据冒烟 API
