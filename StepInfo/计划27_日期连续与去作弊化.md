# 计划 27 —— 世界日期连续（断点续跑）+ 生成去作弊化

> 依据：`StepInfo/00_需求与规则.md` §一.12/§一.13（已重读）+ 用户 2026-08 三条指令。

## 用户指令（原始转述）
1. **世界日期连续**：一个世界就是连续时间延续；刚创建无日期；每天把传递到下一天的信息保存下来；之后若开始模拟下一天，应读取前一天数据继续模拟（像游戏存档/读档）
2. **生成去作弊化**：世界/家庭/人物生成时不得出现任何与用电行为强相关的词条（是否用智能家居/电动车、省电等），用电行为应自发涌现
3. **所有阻塞聊天行为放操作系统后台**（background_runner，秒级返回，事后轮询日志）

## 做了什么
### 日期连续
- `World._resume_date()`：读 `worlds/<id>/state.json` 的 date → 返回下一天；无 state → 默认日期
- `World.save_state()`：每天模拟结束写 `{date, memory_days}`（跨天记忆持久化）
- `HouseholdMemory.load_days()`：恢复历史记忆（昨天行为影响今天）
- simulate.py / population_runner.py：`--date` 缺省 = 自动续跑
- 验证：无 state → 04-21 开始；有 state(04-21) → **04-22 开始 + 恢复 1 天记忆**

### 去作弊化
- 移除：`energy_awareness` 字段、`big_five_to_energy_awareness()`、EV 预设（`_home_by_income` 的 with_ev）
- BIG_FIVE_TEXT 中性化（"会主动关灯省电"→"作息规律、做事细致"）
- analyze_groups 兼容缺失字段（标记"未知"）
- 测试：`test_no_energy_awareness_in_generation`（生成 blob 不含 节能/省电/电动汽车/关灯）
