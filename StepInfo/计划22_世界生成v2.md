### Big Five → 能源行为的心理学映射（实证基础）
- **尽责性 (Conscientiousness) 高** → 节能行为强、作息规律（实证：尽责者更节能）
- **开放性 (Openness) 高** → 接受新技术（EV/太阳能/智能家居）
- **外向性 (Extraversion) 高** → 社交外出多、在家时间短
- **神经质 (Neuroticism) 高** → 对价格/危机更焦虑、政策响应更剧烈
- **宜人性 (Agreeableness) 高** → 更受社会规范影响（nudge 响应强）

## 设计（世界生成 v2）

### 1. 人格模型：Big Five (OCEAN) 五维评分（每维 1-10）
- 每个成员采样五维分数 → 生成中文行为描述（喂给 prompt）
- 五维 → energy_awareness / habits / 新闻敏感度 / 政策响应倾向 的确定性映射
- household.json 的 personality 扩展：`{"big_five": {...}, "traits": [...], "energy_awareness": "高"}`

### 2. 垂直家庭类型（4 类 → 8 类）
现有：young_couple / family_with_kids / single_living / share_house
新增：
- **multigenerational** 多代同堂（3 代同住，老人+中年+青年）
- **single_parent** 单亲家庭（1 成人+1-2 孩子）
- **retired_couple** 退休夫妇（65+）
- **international_student** 国际学生合租（Clayton 特色：Monash 大学区，census 中位年龄 28 佐证）

### 3. 属性关联链（统计校准）
```
年龄 → 职业/学生 → 收入档 → 住房类型/面积 → 电器配置（EV/空调数/热水器）
成员间关联：夫妻年龄差 ≤5、孩子年龄=父母年龄-25~35、合租者年龄 18-30
```
- 校准锚点：clayton_3168_*.csv（中位年龄 28、中位月供 2000、住宅 7150 套）
- 文化多样性：中文/印度/越南/澳洲姓名的混合池（Clayton 真实多元社区）

### 4. 配额与多样性保障
- 家庭类型配额（census 校准）：年轻夫妇 25% / 有孩 20% / 合租 15% / 独居 15% / 学生 10% / 多代 5% / 单亲 5% / 退休 5%
- fringe 群体显式配额（呼应 WGAN 论文的警告）
