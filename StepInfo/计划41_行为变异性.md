# 计划41:跨日行为变异性分析(DR 定向的第二个支柱)

## 做什么

为 LLMWorld 增加"跨日行为变异性"分析:读取世界内各家庭某场景下的
**多日**负荷曲线(所有可用日期),计算每个家庭的行为变异性指标
(逐小时跨日变异系数、峰时漂移、日总用电变异),输出排序报告并前端展示。
与计划40聚类互补:**聚类=同日内的形状分群,变异性=跨日行为稳定性**。

## 为什么(论文依据 + 思考过程)

搜索过程:arXiv 搜索 "social comparison electricity"(限速 429)→
改用 arXiv search UI 搜 "residential electricity load variability flexibility",
从 7 篇结果中选定 2 篇直接相关的:

1. **Zhou, Balandat & Tomlin (2016), arXiv:1607.00595** (UC Berkeley)
   《Residential Demand Response Targeting Using Machine Learning with
   Observational Data》:用观测数据估计 DR 响应,发现
   **用电模式更不规律(高变异性)的用户更可能在 DR 事件中削减用电**。
   → 思考:本项目已验证 TOU/nudge 政策有群体效应(计划8/9),但
   "哪些家庭会响应"从未分析。变异性是论文给出的最强个体预测因子,
   正好补上"个体层面政策响应预测"缺口。
2. **Jin et al. (2021), arXiv:2102.11027** (LBNL)
   《Investigating Underlying Drivers of Variability in Residential Energy
   Usage Patterns》:用 adaptive K-means 聚类 "household-days"(每户每日
   曲线作为样本),研究负荷形状变异的驱动因素;指出
   **变异不等于灵活性,需要按个体细分**。
   → 思考:其 "household-days" 思路=每户多日曲线逐日标签变化,
   本项目变异性指标(逐小时 CV/峰时漂移)正是该思想的量化。
3. **Dent et al. (2014), arXiv:1409.1043**(计划40已引):行为变异性聚类,
   高变异性家庭对激励更敏感 → 与 Zhou 2016 相互印证。

## 怎么做

1. `Implement/engine/load_features.py` 新增(纯逻辑):
   - `hourly_cv_curve(daily_hourly)`:24 维,每小时跨日变异系数 CV=std/mean
     (mean=0 时该小时 CV=0)
   - `variability_index(daily_hourly)`:逐小时 CV 的均值(0~∞,0=完全规律)
   - `peak_hour_shift(daily_hourly)`:每日峰时列表的样本标准差(小时单位)
   - `daily_kwh_cv(per_day_kwh)`:日总用电的变异系数
2. `Implement/analyze_variability.py`(CLI):
   - 扫描 `outputs/<world>/<postcode>/<house_id>/<scenario>/<date>/用电信息/`
     每户全部日期曲线(`--date` 缺省=全部日期)
   - 每户:variability_index / peak_hour_shift / daily_kwh_cv /
     hourly_cv_curve / n_days
   - 输出 `outputs/<world>/analysis/variability_<scenario>.json`:
     per_house 按变异性排序 + 高低分组(half split)+ 汇总统计
   - 打印报告(最规律/最不规律家庭)
3. `server.py`:`GET /api/worlds/<id>/variability/<scenario>`
4. 前端:新增"行为变异性"面板——每户变异性排序条形图(canvas)
   + 高/低变异性分组表 + 逐小时 CV 曲线
5. `test_offline.py` TestVariability:
   - 完全重复日 → variability_index=0, peak_hour_shift=0
   - 峰时漂移日 → peak_hour_shift>0
   - 日用电波动 → daily_kwh_cv 正确
   - hourly_cv_curve 形状与计算正确

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成多日数据跑 CLI 冒烟(规律户 vs 波动户输出正确)
- server API 返回正确,前端面板可渲染
