# 计划 23 —— 环境信息开放接口（天气/气温：真实 / 配置随机 / 手工）

> 依据：`StepInfo/00_需求与规则.md`（已重读）+ 用户需求：环境信息（天气/气温等）做成开放接口——提供了就按真实数据，没提供就从配置文件随机取样/直接随机/手工配置范围内随机。

## 设计

```
EnvironmentInterface.get_weather(location, date, season)
  mode = config.ENV_MODE
  1. real   → WeatherAPI.get_history（真实 API；失败/无 key 自动回退 config 模式）
  2. config → 按季节从墨尔本气候表采样（温度范围 + 天气分布，随机但种子可复现）
  3. manual → 读 Implement/env_manual.json（固定值或 [min,max] 范围 + 天气/湿度）
  返回统一结构：{temperature:{min,max,avg}, condition, humidity, mode}
```

config.py 新增：
- `ENV_MODE = "config"`（默认随机，零依赖）
- `MELBOURNE_CLIMATE`：四季温度范围 + 天气概率分布（墨尔本气候校准：夏天 24-38℃、冬天 7-16℃ 等）
