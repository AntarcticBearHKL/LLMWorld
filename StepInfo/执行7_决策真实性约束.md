# 执行 7 —— 决策真实性约束（EV 充电滥用修复）

> 对应 `计划7_决策真实性约束.md`。

## 实际做了什么

1. **config.py 新增 `APPLIANCE_DAILY_CAP_MINUTES`**：14 类电器每日使用分钟硬上限（EV 4h、热水器 45min、空调 6h、电磁炉 2h 等），一处修改全局生效
2. **energy_calculator 实现超限截断**：`_apply_daily_cap()` 按电器累计当日已用分钟；超限截断并记 `[超限截断]` 警告（不静默）；段标记 `capped: true`
3. **step4 prompt 增加"典型使用时长"表**：12 类电器的典型时长 + "充满即停"充电指南 + 明确"一天最多充 4 小时"
4. **修复 Windows 控制台 GBK 编码问题**：`✓/✗` 字符打印崩溃 → 改 `[符合约束]/[违反约束]`
5. 测试：新增 EV 12h→4h 截断单测 → **26 项全绿**

## 验证结果（pop02 重跑：10 户 × 1 天，修复后）

### 逐户分布对比
| 户 | 修复前 kWh | 修复后 kWh | 修复前峰值 | 修复后峰值 |
|---|---|---|---|---|
| house_0002 | 35.5 | 37.9 | 14.3kW | 8.4kW |
| house_0010 | **107.3** | **29.7** | 14.0kW | 10.4kW |
| 其余 8 户 | 2.1~19.1 | 3.6~12.5 | - | - |

### 聚合指标（修复前 → 修复后）
| 指标 | 修复前 | 修复后 | 判定 |
|---|---|---|---|
| 人口总用电 | 222.9 kWh | **141.5 kWh** | 恢复正常量级 |
| 户均/中位 | 22.3 / 12.1 | **14.2 / 11.8** | 分布健康 |
| 标准差 | 29.6 | **10.5** | 异常户消失 |
| 晚峰时刻 | 17:00 | **18:00（与真实 18:00 偏移 0）** | ✓✓ |
| 谷值时刻 | 14:00 | 5:00 vs 真实 3:00 | 接近 |
| 相关性 | 0.35 | **0.56** | ↑ |
| 峰均比 | 2.52 | 4.78 | 见注 |

注：峰均比仍 4.8 —— 多户 18:00 同步做饭/开空调造成集中晚峰；10 户多样性仍不足（真实系统是数百万户的多样性）。这是 RQ1 规模论证的另一个实证点。
