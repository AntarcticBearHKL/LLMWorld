# 计划42:行为模式迁移分析(household-days 聚类)

## 做什么

实现 Jin et al. (2021) 的 "household-days" 方法论:把世界内
**每户每日曲线**作为独立样本(household-days)做 K-means 聚类,
统计每户跨日的簇序列与**模式迁移次数**(相邻日是否换簇)。
输出:簇中心曲线(代表性日模式)+ 每户主导簇/迁移次数/簇序列,前端展示。
与前两轮互补:计划40=按户聚类(一日形状分群),计划41=变异性指标
(跨日稳定性标量),计划42=跨日模式迁移(模式级别的跨日行为结构)。

## 为什么(论文依据 + 思考过程)

搜索过程:arXiv search UI 搜 "residential load shape clustering
household-days" → 命中唯一 1 篇(即 Jin 2021),确认该方法论在
arXiv 的定位无更强替代 → 直接以该文为实现蓝本。

1. **Jin et al. (2021), arXiv:2102.11027** (LBNL)
   《Investigating Underlying Drivers of Variability in Residential
   Energy Usage Patterns with Daily Load Shape Clustering of Smart
   Meter Data》:对 "household-days" 用(改进的)adaptive K-means 聚类,
   研究形状变异的驱动因素(温度 > 季节/星期);发现顶 3 个模式在
   高温日覆盖约 50% 用电;强调"变异≠灵活性,需按个体细分"。
   → 思考:本项目计划40已做"按户聚类"(每户一条曲线),
   但一个家庭在不同日可能切换行为模式(工作日/周末/热浪日)。
   按 household-days 聚类能揭示:①世界涌现出几种代表性日模式;
   ②每个家庭跨日的模式稳定性(迁移次数=行为规律性的模式级度量)。
   这补充了计划41"峰时漂移"之外的模式级视角。
2. 复用:计划40的 sklearn KMeans(§一.22 库实现)、
   load_features 的 normalize_shape/auto_k(Jin 2021 也用形状聚类)。

## 怎么做

1. `Implement/analyze_behavior_patterns.py`(CLI,复用 load_features):
   - 扫描 `outputs/<world>/<postcode>/<house_id>/<scenario>/<date>/用电信息/`
     每户全部日期曲线
   - 样本 = (house_id, date, normalize_shape(hourly_means(watts)))
   - `--k` 缺省肘部法自动选;sklearn KMeans 聚类样本
   - 每户:主导簇/迁移次数(相邻日簇不同的次数)/簇序列/每日日期
   - 输出 `outputs/<world>/analysis/patterns_<scenario>.json`:
     簇中心曲线+簇内样本、per_house 迁移统计、汇总(平均迁移数)
2. `server.py`:`GET /api/worlds/<id>/patterns/<scenario>`
3. 前端:新增"行为模式迁移"面板——簇中心曲线(canvas,复用画线逻辑)
   + 每户簇序列(彩色小方块,一行一户,一列一天)
   + 迁移次数统计
4. `test_offline.py` TestBehaviorPatterns:
   - 合成数据:两户各 3 天,户 A 模式固定、户 B 第 2 天起换模式
   - 断言:簇数/迁移次数/主导簇正确

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成多日数据 CLI 冒烟(模式固定户 vs 模式切换户)
- server API 返回正确
