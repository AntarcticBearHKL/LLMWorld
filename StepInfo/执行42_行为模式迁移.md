# 执行42:行为模式迁移分析(household-days 聚类)

## 实际做了什么

1. **论文确认**:arXiv search UI 搜 "residential load shape clustering
   household-days" → 唯一命中 Jin et al. 2021 (arXiv:2102.11027),
   确认方法论蓝本无更强替代。
2. **新增 `Implement/analyze_behavior_patterns.py`**(CLI,零注释):
   - 扫描世界某场景下全部 household-days(每户每日曲线)
   - 特征=24h 归一化形状(复用 load_features.normalize_shape)
   - sklearn KMeans 聚类(`--k` 或肘部法自动选,复用 load_features)
   - 每户:簇序列/迁移次数(相邻日换簇计数)/主导簇/日kWh 均值
   - 输出 `outputs/<world>/analysis/patterns_<scenario>.json`:
     簇中心形状+样本列表、per_house 迁移统计、平均迁移数
3. **`server.py`**:`load_behavior_patterns` +
   `GET /api/worlds/<id>/patterns/<scenario>`
4. **前端**:新增"行为模式迁移"面板——每簇中心曲线(canvas,
   复用 drawClusterCanvas)+ 每户簇序列彩色格子(一行一户,一列一天)
   + 迁移次数/主导簇/日kWh
5. **测试**:TestBehaviorPatterns 4 项 → 总 100 项全绿(skipped=5)

## 结果

- `test_offline.py`:100 项 OK(skipped=5)
- CLI 冒烟(2 户 × 3 天,k=2):
  - fixed(峰恒 19:00):迁移 0 次 [0,0,0]
  - switch(峰 8→19→19):迁移 1 次 [1,0,0]
  - 平均迁移 0.5,输出 JSON 正常
- server 重启完成,端点就绪

## 偏差

- 无。Jin 2021 用 adaptive K-means(动态调簇数),本项目用固定 k+
  肘部法(离线可测、可复现),方法论等价(形状聚类 + 逐日标签)
