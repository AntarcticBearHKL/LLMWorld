# 计划110:社区公告注入(轻量社交网络入口)

## 做什么

引擎加入**社区公告板**注入:step1 宏观计划 prompt 增加
`{community_notice}` 占位符,population_runner 支持
`--community-notice "文本"` 传入社区级信息
(如"本社区本周节能目标 5%"/"社区互助:周末集体采购"),
所有家庭同一时间看到——LLM 模拟的第一条
"家庭间共享信息"通道(轻量社交网络入口)。

## 为什么(论文依据 + 思考过程)

1. **Ayres, Raseman & Shih (2013) JEBO**(计划54已引):
   邻居比较/社区信息影响家庭用电 → 社区级信息注入
   是其模拟化。
2. **CoRenew (2026), arXiv:2607.25447**(RefPaper 已存):
   多利益相关者共享情境(社区上下文)是 LLM-ABM
   政策评估要素 → 公告板=共享情境的轻量实现。
3. **Fidone et al. (2026), arXiv:2511.07204**(RefPaper 已存):
   信息耦合是涌现行为前提(计划54 peer-nudge 为户对户,
   公告板为户对全体)。
   → 与 peer-nudge 互补:peer-nudge 是"数据反馈",
   公告板是"文本事件"(可与新闻剧本区分:新闻=宏观世界,
   公告=社区内部)。

## 怎么做

1. `prompts/simulate_step1_macro_plan.md`:加
   `{community_notice}` 占位符段(空时无输出)
2. `engine/planner.py`:`generate_plans(time_obj, community_notice="")`
   → prompt.load 传参
3. `engine/world.py`:`simulate_day(..., community_notice="")`
   → planner 传递
4. `population_runner.py`:`--community-notice` 参数
5. 测试:模板渲染含占位符;planner 调用链默认空不破坏

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 模板渲染人工检查
