# 执行62:异常户检测

## 实际做了什么

1. **论文搜索**:arXiv search UI 搜 "anomaly detection smart meter
   residential electricity"(0 结果)→ "electricity theft detection
   consumption pattern"(7 篇)→ 选定 Banik 2023(综述,
   arXiv:2306.02473)/ Glauner 2017(消费模式特征,arXiv:1702.03767)/
   Olowookere 2026(异常消费检测,arXiv:2604.03344)
2. **新增 `Implement/analyze_anomalies.py`**:
   - 复用 scan_house_profiles(最新日曲线)
   - 特征:total_kwh / peak_to_mean / load_factor / overlap_count
   - 户数 ≥3 时逐维 z-score;|z|>2 标记(高/低)
   - 综合:anomaly_flags + max_abs_z;输出
     anomalies_<scenario>.json(per_house + anomalies 列表)
3. **`server.py`**:`GET /api/worlds/<id>/anomalies/<scenario>`
4. **前端**:新增"异常户检测"面板(表格:各特征值+z 着色+
   异常原因;红=偏高蓝=偏低)
5. **测试**:TestAnomalies 4 项(高耗能标记/叠加计数/
   空数据/样本不足)→ 148 项全绿
