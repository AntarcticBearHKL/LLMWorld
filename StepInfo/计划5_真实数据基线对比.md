# 计划 5 —— 真实电力数据基线对比（RQ3 起点）

> 依据：`StepInfo/00_需求与规则.md`（已重读：数据围绕 3168 Clayton；每步必须有验证）。

## 为什么做这步

论文 RQ3/阶段一的验证目标：模拟负荷是否具备真实世界的统计特征（早晚双峰、工作日-周末差异、季节变化）。项目已有 `vic_electricity_data.csv`（OpenElectricity 维州 VIC1 区域真实需求+电价，2026-06-23 周二，小时粒度）——恰好模拟日 2026-04-21 也是周二，可比。

本步做第一个量化对齐：**人口模拟负荷 vs 维州真实负荷的形状对比**，产出对比报告 + 图表，作为论文 RQ3 的第一组证据。

## 做什么

| # | 任务 | 文件 | 验收 |
|---|---|---|---|
| 1 | 基线对比脚本：加载真实数据 + 人口模拟曲线，计算形状指标并出图 | 新建 `Implement/validate_baseline.py` | 产出 JSON 报告 + PNG 对比图 |
| 2 | 指标定义：归一化小时曲线、早晚峰时刻/峰谷比、峰均比、逐小时相关、双峰强度 | 同上 | 指标可解释、可复现 |
| 3 | 离线测试：指标计算函数正确性 | `test_offline.py` 扩展 | 全绿 |
| 4 | 真实运行：pop01 聚合曲线 vs VIC1 | 运行 | 报告 + 图 |

## 指标设计（不懂代码也能看懂）

- **归一化小时曲线**：每小时均值 ÷ 全天均值（消除量纲差异：MW vs W）
- **晚峰时刻**：归一化曲线最大值所在小时
- **峰均比**：峰值 ÷ 全天均值（形状"尖"的程度）
- **双峰强度**：早晨峰(6-10点)与晚峰(16-21点)的相对高度（双峰是否明显）
- **逐小时相关性**：两条归一化曲线的皮尔逊相关系数
- **谷值时刻**：最低小时

## 怎么验证

1. `test_offline.py` 全绿
2. `python Implement/validate_baseline.py --world pop01` → 报告 JSON + `outputs/pop01/baseline/对比图.png`
3. 人工解读：双峰是否重合、峰均比量级是否合理（真实住宅晚峰 18-20 点，模拟 18:15 聚合峰——预期一致）
4. git 提交

## 学术依据

- **RQ3 对齐基准**（论文 2.7 节）：模拟需重现真实负载的统计特征才能作为政策实验平台
- **Richardson et al. (2010)**：分钟级合成负荷应匹配真实数据的时空结构——归一化形状对比是第一步
- 数据来源：OpenElectricity（openelectricity.org.au）维州区域需求，项目已有 CSV（test_openelectricity.py 的产物）
