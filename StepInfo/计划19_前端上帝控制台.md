# 计划 19 —— 前端上帝控制台 + 自动刷新（POST 事件注入）

> 依据：`StepInfo/00_需求与规则.md`（已重读：前端实用清晰、每步新功能同步前端）。

## 为什么做这步

上帝模式（计划13）目前只能命令行/JSON 注入。把"上帝"搬进浏览器：前端面板直接注入事件（POST API 写 events.json，模拟中每天重读 → 实时生效）。同时加 10 秒自动刷新，让"当前模拟世界的变动"实时可见。

## 设计

```
POST /api/worlds/<id>/events
body: {"date": "2026-04-21", "title": "...", "content": "...", "source": "上帝"}
→ 读 events.json → 追加 → 写回 → 返回新事件列表

前端"上帝控制台"面板：
  日期 [ ] 标题 [ ] 内容 [ ] 来源 [上帝] → [注入事件]
  事件列表即时显示；每 10 秒自动刷新所有面板
```
