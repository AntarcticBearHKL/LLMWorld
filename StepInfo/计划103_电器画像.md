# 计划103:电器使用画像分析(appliance usage profile)

## 做什么

新增 `Implement/analyze_appliance_usage.py`:从每户电器级 JSON
(上帝视角)聚合电器使用画像:
- 世界级:各电器总能耗占比排行/平均使用时长/使用次数
- 每户:电器数/总能耗/最多用电器
输出报告 + 前端面板,直观展示"哪类电器主导模拟用电"
(RQ1 行为→电器→能耗链路的电器端分析)。

## 为什么(论文依据 + 思考过程)

1. **Gunkel et al. (2022), arXiv:2210.03524**(RefPaper 已存):
   电器类别(热泵/EV/基载)对聚合用电的贡献分析
   → 本工具=模拟世界的电器贡献排行。
2. **Azad et al. (2023), arXiv:2306.05017**(计划91已引):
   NILM 的电器级数据价值 → 上帝视角电器数据是 NILM
   基准的标签源,画像分析展示其内容。
3. **运维经验**:电器 JSON 已存在(energy_calculator 产物),
   只缺聚合视图。

## 怎么做

1. `Implement/analyze_appliance_usage.py`:
   - 复用 analyze_nilm.load_true_appliances(每户电器列表)
   - 世界级:按电器名聚合 总能耗/占比/户数/平均时长
   - 每户:电器数/总能耗/TOP1 电器
   - 输出 appliance_usage_<scenario>_<date>.json
2. `server.py`:`GET /api/worlds/<id>/appliance-usage/<scenario>/<date>`
3. 前端:新增"电器使用画像"面板(排行表)
4. 测试:TestApplianceUsage——合成电器数据聚合正确、
   空数据报错

## 怎么验证

- `python Implement/test_offline.py` 全绿
- 合成数据 CLI 冒烟
