# 计划 13 —— 外界信息/新闻摄入 + 上帝模式（World Events）+ 并行开发提效

> 依据：`StepInfo/00_需求与规则.md`（已重读）+ 用户新增需求：
> 1. **每个 agent 每天固定时间获取外界信息**（如看新闻），结合自身个性分析，影响行为
> 2. **上帝模式**：运行者（用户）作为"上帝"向世界注入信息（税收、战争等），agent 在特定时间获取并响应
> 3. **并行开发**：多开并行子任务提升效率

## 为什么做这步

当前系统里 agent 只感知"天气/季节/节假日"，**没有任何外部世界信息**——论文 RQ2 的"社会事件干预"（战争、政策公告、能源危机）正是要研究这类信号如何传导到行为。新闻/上帝模式让外部世界与模拟世界联通，同时给用户一个直观的"上帝控制台"。

## 设计（保持可读）

```
新闻台 NewsBoard（engine/news.py）
  NewsItem: 日期/时间/标题/内容/来源/类型
  加载：worlds/<world_id>/events.json（上帝写的剧本，模拟中每天重读 → 运行中可改）
  过滤：available_on(date) —— 发布日期 <= 当前日
  渲染：render_for_prompt(date) → markdown 文本

注入点（两处，与记忆/政策同一模式）：
  1. 第一层 宏观计划 prompt：{world_news} —— agent 早上获取新闻，结合性格分析影响全天安排
  2. 第四层 用电决策 prompt：{world_news} —— 电价/能源类新闻直接影响电器决策

上帝接口（三选一，全部支持）：
  a. worlds/<world_id>/events.json 静态剧本（推荐，可随时编辑）
  b. 命令行 --event "2026-04-21|政府宣布开征空调用电附加税10%"
  c. 代码 API：world.news.add_event(NewsItem(...))

个性分析：新闻章节要求"结合你的性格/职业/节能意识分析这些信息对你的影响"
（现有 prompt 已带 personality，天然支持）
```
