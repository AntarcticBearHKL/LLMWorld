# 世界模拟可视化

全屏六边形交互式可视化界面，用于展示世界模拟数据。

## 功能特性

- **全屏沉浸式设计**
  - 无边框全屏显示
  - 悬浮式导航和控制面板
  - 流畅的视觉体验

- **三层六边形导航**
  - 第一层：世界视图（显示街区）
  - 第二层：街区视图（蜂窝状展示所有家庭）
  - 第三层：时间线视图（展示家庭所有成员的详细日程）

- **时间线展示**
  - 同时显示所有家庭成员的时间线
  - 每个成员有独立的彩色标题栏
  - 显示每个时间段的位置、活动和使用的电器
  - 显示每个成员和家庭总用电量

- **日期导航**
  - 自动扫描可用日期
  - 前后天切换按钮
  - 一天一天查看家庭时间线

- **实时刷新**
  - 🔄 刷新按钮随时更新最新数据
  - 自动扫描新生成的模拟数据

- **交互功能**
  - 鼠标拖拽平移视图
  - 鼠标滚轮缩放
  - 面包屑导航快速返回上层

## 使用方法

1. 启动本地服务器：
```bash
python render/start_server.py
```

或直接双击：
```bash
render/start.bat
```

2. 在浏览器中打开：
```
http://localhost:8000/render/
```

## 数据结构

程序会自动读取以下数据：
- `worlds/{world_id}/world.json` - 世界基本信息
- `worlds/{world_id}/{postcode}/district.json` - 街区信息
- `worlds/{world_id}/{postcode}/{house_id}/household.json` - 家庭信息
- `outputs/{world_id}/{postcode}/{house_id}/{date}/04_第四层_批量用电决策_{member_name}.json` - 时间线数据

## 界面说明

- **六边形颜色**：不同颜色代表不同的家庭类型
- **点击六边形**：进入下一层级
- **面包屑导航**：点击可快速返回上层
- **刷新按钮**：更新至最新数据
- **时间线标签**：不同颜色表示电器状态（绿色=使用中，黄色=充电中）
- **成员头像**：👨 男性 / 👩 女性

## 技术特点

- 无需预生成索引文件，自动扫描可用日期
- 轻量级设计，无外部依赖
- 响应式布局，适配不同屏幕尺寸
