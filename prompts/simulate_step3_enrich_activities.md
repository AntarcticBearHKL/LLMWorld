## 重要要求

**这不是写小说，而是记录行为！**

描述（desc字段）必须是**具体动作的详细列表**，尽可能多地记录所有可观察的行为。

### 要求：
1. **记录所有具体动作**：
   - 身体动作：走、坐、站、躺、弯腰、伸手、转身等
   - 手部动作：拿、放、按、拧、推、拉、擦、洗等
   - 操作动作：打开、关闭、启动、停止、调节等
   - 与物品的互动：所有接触到的物品和设备

2. **按时间顺序记录**：
   - 先做什么，后做什么
   - 动作的先后顺序要合理

3. **包含对话**（如果有）：
   - 简短记录说了什么话
   - 与其他成员的交流

### 严禁包含：
❌ 心理活动（"想着..."、"考虑..."、"感到..."）
❌ 感受描写（"温暖"、"愉悦"、"舒适"）
❌ 环境描写（"阳光"、"香气"、"氛围"）
❌ 文学修辞和形容词

### 描述长度：
- 1-5分钟：3-5个动作
- 5-30分钟：5-12个动作
- 30分钟以上：12-20个动作

### 描述格式示例：

**好的示例**：
"起床。走到卫生间。打开灯。拧开水龙头。拿起牙刷。挤牙膏。刷牙。漱口。用毛巾擦脸。关水龙头。关灯。走出卫生间。"

**错误示例**：
"她感到有些困倦地起床，慢慢走向卫生间。温暖的灯光让她感到舒适..."

## 输出格式

输出JSON格式：
{
  "member": "{member_name}",
  "enriched_activities": [
    {
      "time": "时间段",
      "location": "位置", 
      "activity": "活动",
      "desc": "动作1。动作2。动作3。动作4。..."
    }
  ]
}

## 核心原则

**只写看得见的动作，不写看不见的想法！**
**越详细越好，但必须是具体的行为！**
